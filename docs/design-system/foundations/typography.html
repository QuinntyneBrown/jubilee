Typography

Archivo at 110% width for headings and the wordmark, Inter for everything else; sixteen role shorthands carry size, weight, line height and family together.

WCAG 2.2 AAArchivo + Inter16 roles

Overview

Two families. Archivo sets every display role and the jubilee wordmark at 110% width (--font-variation-display), always bold 700, with --letter-spacing-tight (-0.025em) tracking; the wordmark uses --letter-spacing-tighter (-0.03em). Inter sets everything else. Both load from Google Fonts through an @import at the top of assets/components.css and fall back to system fonts offline.

  • Body text is 16px. The smallest text is 11px (--font-size-2xs), used only for tab-bar labels and count badges.
  • Display roles use tight line heights: 1.05 for the display h1, 1.08 for the page h1, 1.25 for card names and 1.3333 for h2 and h3. Body uses 1.5; taglines use 1.375.
  • Use the sixteen --text-* role shorthands, not ad-hoc sizes: font: var(--text-label).
  • The font shorthand resets font-variation-settings. When a display role is set inline or in a new rule, add font-variation-settings: var(--font-variation-display) and letter-spacing: var(--letter-spacing-tight) after it.

Medium (500) sets nav links, chips and row names. Semibold (600) sets buttons, field labels, subheads and badges. Bold (700) sets every Archivo display role, including prices; nothing is heavier.

Measure and responsive type

  • Paragraphs cap at --layout-measure (65ch); empty-state text at 36ch; hero headings at --layout-container-prose (48rem).
  • Heading sizes step once, at 640px (40rem). The h1 goes from --font-size-h1-sm (28px) to --font-size-4xl (36px); the display h1 from --font-size-display-sm (32px) to --font-size-5xl (48px); the h2 from 20px to 24px; card names from 16px to 18px; the featured card name from 24px to 30px. Steps, not viewport units, so zoom works.
  • Prices and counts use font-variant-numeric: tabular-nums.
  • Long business names wrap with overflow-wrap: anywhere; card names and taglines clamp to two lines.

Accessibility

  • All sizes are rem, so text scales with browser settings (1.4.4); layouts reflow at 320px.
  • Line height 1.5 and paragraph spacing survive the 1.4.12 text-spacing override; nothing has a fixed height that would clip.
  • Uppercase is limited to short overlines and sidebar and menu group labels, with 0.04em tracking; never sentences. Badges are normal case.

Usage

  • One h1 per page; headings in order. Dialog titles are h2 styled with --text-h3.
  • Sentence case everywhere, including buttons and headings; see Content.
