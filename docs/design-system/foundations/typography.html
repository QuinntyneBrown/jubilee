Typography

Archivo for headings and the wordmark, Inter for everything else; twelve role shorthands carry size, weight, line height and family together.

WCAG 2.2 AAArchivo + Inter12 roles

Overview

Two families. Archivo (display, 600–800) sets headings; the jubilee wordmark is Archivo bold (700) at 110% width with −0.03em tracking (see Lockup). Inter sets everything else. Archivo ships with the design system as one variable WOFF2 (assets/fonts/Archivo.woff2, declared in tokens.css), so headings and the wordmark render the same from disk as in the design reference; Inter falls back to the system UI stack in the mocks. The product self-hosts both as WOFF2 with font-display: swap.

  • Body text is 16px and never smaller than 12px (captions).
  • Headings use tighter line height (1.2–1.3) and text-wrap: balance; body uses 1.5.
  • Use the twelve --text-* role shorthands, not ad-hoc sizes: font: var(--text-label).

Medium (500) is the label weight; semibold (600) marks the primary button, selected tabs and prices; bold and extrabold belong to Archivo headings.

Measure and responsive type

  • Paragraphs cap at --layout-measure (65ch); empty-state text at 36ch; hero headings at 18ch.
  • The h1 steps from --font-size-3xl (30px) on phones to --font-size-4xl (36px) at 768px; the hero h1 reaches --font-size-5xl (48px) at 1024px. Steps, not viewport units, so zoom works.
  • Prices and counts use font-variant-numeric: tabular-nums.
  • Long business names wrap with overflow-wrap: anywhere; taglines clamp to two lines.

Accessibility

  • All sizes are rem, so text scales with browser settings (1.4.4); layouts reflow at 320px.
  • Line height 1.5 and paragraph spacing survive the 1.4.12 text-spacing override; nothing has a fixed height that would clip.
  • Uppercase is limited to short overlines and badges with 0.04em tracking; never sentences.

Usage

  • One h1 per page; headings in order. Dialog titles are h2 styled with --text-h3.
  • Sentence case everywhere, including buttons and headings; see Content.
