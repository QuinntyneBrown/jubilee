Foundation

Spacing

A 4px spacing scale and three control heights. Components stay at or under 24px inside; layouts use 24px and up between.

WCAG 2.2 AA4px base
  • Overview
  • Scale
  • Inside and between
  • Padding by component size
  • Usage
  • Tokens

Overview

A 4px scale from 0 to 96px. The token number is the multiple of 4 (--space-6 = 24px). The half steps --space-0-5, --space-1-5 and --space-2-5 are 2px, 6px and 10px. Every padding, gap and margin maps to a step, and every step is a value the design reference uses.

Inside and between

  • Inside a component: ≤ --space-6. Icon to label --space-1–--space-2; field help --space-0-5 (2px) under its label; label to control --space-2-5 (10px); between buttons --space-2–--space-3; card and dialog padding --space-6; toast and alert padding --space-4.
  • Between components: ≥ --space-6. Form groups --space-7 (28px); page sections --space-14 (56px), and a ruled section adds --space-8 (32px) of padding under its rule; directory groups --space-10. .page has --space-6 (24px) of top padding, --space-10 (40px) from 768px, and --space-12 (48px) at the bottom.
  • Card grids use a --space-8 (32px) row gap and --layout-gutter between columns: 16px, 24px from 640px.

Usage

  • Use gap on flex and grid parents rather than margins on children (.stack, .cluster).
  • Never write a pixel value in a component; if the scale lacks a step, the design is off-grid.
  • Spacing never scales with viewport width; breakpoints change layout tokens instead (Layout).
