Foundation

Spacing

A 4px spacing scale and three control heights. Components stay at or under 24px inside; layouts use 24px and up between.

WCAG 2.2 AA4px base
  • Overview
  • Scale
  • Inside and between
  • Padding by component size
  • Usage
  • Tokens

Overview

A 4px scale from 0 to 96px. The token number is the multiple of 4 (--space-6 = 24px). Every padding, gap and margin in the mocks maps to a step; off-grid values were corrected during extraction (see the drift log in the README).

Inside and between

  • Inside a component: ≤ --space-6. Icon to label --space-1–--space-2; label to input --space-1; between buttons --space-3; card and dialog padding --space-6; toast and alert padding --space-4.
  • Between components: ≥ --space-6. Form fields --space-4–--space-6; page sections --space-8; directory columns --space-12; page bottom padding --space-16 (clears the phone tab bar).
  • Card grids use --space-6 rows × --space-4 columns on phones and --space-8 × --space-6 from 768px.

Usage

  • Use gap on flex and grid parents rather than margins on children (.stack, .cluster).
  • Never write a pixel value in a component; if the scale lacks a step, the design is off-grid.
  • Spacing never scales with viewport width; breakpoints change layout tokens instead (Layout).
