Foundation

Motion

Seven durations and four easings. Short, functional motion that disappears under reduced motion.

WCAG 2.2 AA
  • Overview
  • Durations
  • Easing
  • Choreography
  • Reduced motion
  • Tokens

Overview

Motion is short and functional: it shows where something came from (a sheet slides up, a toast rises) and confirms a state change (a switch thumb slides). Nothing animates for decoration, and reduced motion removes all of it through the tokens.

Durations

Each dot travels 6rem using the named duration.
TokenUse
fast 120mshover, colour, border, tooltip fade
base 200msmenus, toasts, switches, backdrop
slow 320msdialogs, sheets, progress fill
deliberate 500mspage-level transitions
spin 800msone spinner revolution
loop 1400msskeleton shimmer, indeterminate bar, pulse

Easing

Same distance and duration, four curves.
  • standard for things that move within the page.
  • enter (decelerate) for things arriving: dialogs, toasts, menus.
  • exit (accelerate) for things leaving.
  • spring sparingly, for a confirmation that deserves a small overshoot.

Choreography

  • Dialogs: backdrop fades (base), panel scales in from 0.96 (slow) on ≥ 640px and slides up as a sheet below.
  • Toasts slide up 16px and fade in (base); leaving fades and drops 8px with --ease-exit.
  • Menus scale in from their trigger corner (fast).
  • Never animate layout properties (width, height, top) on large surfaces; use opacity, translate and scale.

Reduced motion

  • Under prefers-reduced-motion: reduce the tokens set fast, base, slow and deliberate to 0.01ms, so every transition and reveal becomes instant with no component media queries.
  • Looping decoration (shimmer, pulse, indeterminate bar) is switched off in components.css, because a near-zero infinite loop would flicker.
  • --duration-spin is not zeroed: a spinner is status. Nothing flashes more than three times a second (2.3.1).
