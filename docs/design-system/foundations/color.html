Foundation

Color

Ink, cream and gold, with green for trust. Every colour is a named role with a light and a dark value, and every pairing is contrast-checked.

Overview

Jubilee's colour is ink and cream with one warm accent. Gold (--palette-gold-400, #ffb81c) marks the primary action, the selected chip, the current tab and unread counts. Green (--palette-green-500) means verified, success and links. Blue, amber and red are reserved for information, warnings and danger. Everything else is a neutral from the ink ramp.

  • Gold always carries ink text (--color-fg-on-accent) and is never used as text: gold on cream is 1.6:1.
  • Gold controls get a darker edge, --color-accent-border (gold-600), which reaches 3:1 against white and cream.
  • The brand band (top bar, hero, CTA band) is ink in both themes: --color-bg-brand with the --color-*-on-brand tokens.
  • Components never read --palette-* directly; they read the semantic roles below, which each theme redefines.

Primitive ramps

The raw palette. Ink runs from cream (25) to near-black (975); gold, green, blue, amber and red carry only the steps a role needs.

Status colours

Each status has a tint background, a text colour, a border, an icon colour, an icon colour for inverse surfaces (toasts) and a solid fill. Status is always colour + icon + words (1.4.1).

Usage

  • Text on surfaces: --color-fg-default, -muted for secondary, -subtle for metadata and placeholders. All three pass 4.5:1 on every surface.
  • Links and accent text are green (--color-fg-link, --color-fg-accent) in light; in dark accent text becomes gold-300, which passes on ink.
  • Use --color-border-strong for anything a person must see to operate (inputs, secondary buttons, chips); --color-border-default only for decorative dividers.
  • Adding a brand theme: add a [data-theme="<name>"] block that overrides semantic tokens only, add its pairs to the JSON and run the checker. See Theming.
