Responsive

How every Jubilee component behaves at phone, tablet and desktop widths, plus touch rules and the test matrix.

Overview

Mobile first at 360px, verified at 360, 768 and 1280px in both themes. Breakpoints change layout tokens, heading sizes (one step, at 640px) and a handful of component rules; nothing scales fluidly with the viewport.

Touch and pointer

  • Every target is ≥ 24px (--target-min, 2.5.8). Visible controls are 36, 40 or 48px tall. Under (pointer: coarse), buttons, chips, nav links, tabs, pagination and standalone links get an invisible hit area at least 44px tall (--target-comfortable); their visible size does not change. Accordion summaries and bottom-sheet menu rows are 44px tall.
  • (hover: none) reveals hover-only affordances such as table row actions permanently.
  • Fixed bottom elements add env(safe-area-inset-bottom); full-height layouts use 100dvh.
  • Horizontal scrollers snap (scroll-snap-type: x proximity) and keep a visible next item as an affordance.

Usage

  • Write min-width queries in rem; add a breakpoint only by adding a token.
  • Hide with .only-mobile, .only-desktop and .only-narrow (all switch at 768px), never by deleting content from the DOM order.
  • See Layout for the grid.
