Responsive

How every Jubilee component behaves at phone, tablet and desktop widths, plus touch rules and the test matrix.

WCAG 2.2 AA
  • Overview
  • Behaviour by breakpoint
  • Touch and pointer
  • Testing matrix
  • Usage

Overview

Mobile first at 360px, checked at 360, 768 and 1280px in both themes. Breakpoints change layout tokens and a handful of component rules; type and spacing never scale with the viewport.

Touch and pointer

  • Every target is ≥ 24px (2.5.8); nav links, tabs, rows and primary mobile actions are 44px (--target-comfortable).
  • (hover: none) reveals hover-only affordances such as table row actions permanently.
  • Fixed bottom elements add env(safe-area-inset-bottom); full-height layouts use 100dvh.
  • Horizontal scrollers snap (scroll-snap-type: x proximity) and keep a visible next item as an affordance.

Testing matrix

ViewportThemesCheck

200% and 400% zoomlightreflow to 320px CSS width (1.4.10)

Usage

  • Write min-width queries in rem; add a breakpoint only by adding a token.
  • Hide with .only-mobile, .only-desktop (768px) and .only-narrow (1024px), never by deleting content from the DOM order.
  • See Layout for the grid.
