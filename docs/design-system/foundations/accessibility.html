Overview

Jubilee targets WCAG 2.2 AA in both themes. These are the system's commitments; every component page answers them in its Accessibility section (role and APG pattern, keyboard, focus, labelling, live contrast, motion, touch).

Perceivable

RequirementSCRule in Jubilee
Text contrast1.4.3Body, label and secondary text ≥ 4.5:1 on every surface it sits on, both themes (contrast-pairs.json). Gold is never text.
Non-text contrast1.4.11Input borders, gold control edges (--color-accent-border), focus rings, meaningful icons ≥ 3:1.
Use of colour1.4.1Status is colour + icon + words; links are underlined; optional fields say "optional"; verified carries hidden text.
Resize and reflow1.4.4, 1.4.10rem everywhere; reflow to 320px; only tables and scrollers scroll sideways.
Text spacing1.4.12No fixed heights on text containers.
Images1.1.1Product photos have alt text naming the item; decorative SVG is aria-hidden; icon-only controls have aria-label.
Motion2.3.3Durations zeroed under reduced motion in tokens.
Input purpose1.3.5autocomplete on name, e-mail, phone, postal code, password fields.

Operable

RequirementSCRule in Jubilee
Keyboard2.1.1, 2.1.2Everything works with Tab, Enter, Space, Esc and arrows where the APG pattern says so; only modal dialogs trap focus, and Esc releases.
Focus visible and appearance2.4.7, 2.4.11One ring: 2px --color-focus-ring, 2px offset; gold on the brand band and in dark.
Focus not obscured2.4.11scroll-padding clears the sticky top bar and tab bar; toasts never cover the focused element.
Target size2.5.8≥ 24px everywhere, 44px for nav, tabs, rows and primary mobile actions.
Timing2.2.1Toasts last ≥ 8s, pause on hover and focus; danger toasts persist.
Bypass2.4.1Skip link to #main on every page; landmarks header, nav, main, footer.
Titles and headings2.4.2, 2.4.6Unique title per page, one h1, ordered headings.
Link purpose2.4.4"View Luzandre.com", not "View"; card links name the business.

Understandable

RequirementSCRule in Jubilee
Labels3.3.2Visible labels on every control; placeholders are examples ("Plumber, lawyer, Bibles…"), never labels.
Errors3.3.1, 3.3.3Error text names the field and the fix; aria-invalid + aria-describedby; a summary links each error and takes focus on submit.
Error prevention3.3.4Delete, unpublish, cancel and decline confirm in a dialog; destructive confirms name the loss.
Accessible authentication3.3.8Paste and password managers allowed; password show toggle; e-mail reset link.
Consistency3.2.3, 3.2.4, 3.2.6Same top bar, tab bar and help link on every page; icons mean one thing.
Language3.1.1lang="en-CA" on every page.

Robust

RequirementSCRule in Jubilee
Name, role, value4.1.2Native elements first; ARIA follows the APG patterns named on each component page.
Status messages4.1.3Toasts in role="status" (danger role="alert"); "Saved" and counts in live regions.

Testing

  • check_contrast.py for every declared pair in both themes; check_design_system.py for labels, names, alt text, landmarks, headings and links; the mocks checker for every mock.
  • Manual per release: Tab through a dialog, a form and the inbox; use VoiceOver or NVDA on sign-up, book-meeting and the request timeline; zoom to 200% and 400%; emulate reduced motion and forced colours.

Component contract

  • Name the element or APG pattern.
  • Give the keyboard map.
  • Say where focus starts and returns.
  • Say what is labelled and how.
  • List the token pairs.
  • Say what animates.
  • Give target sizes and hover alternatives.
