Layout

Five breakpoints, a 4/8/12-column grid, gutters and margins that grow with the viewport, and the page templates the mocks use.

WCAG 2.2 AAMobile first
  • Overview
  • Breakpoints
  • Columns, gutters, margins
  • Page templates
  • Usage
  • Tokens

Overview

Mobile first. Base styles target 360px; breakpoints add columns, gutters and margins through tokens, so components read --layout-* instead of writing their own media queries. Queries use min-width in rem (40rem, 48rem, 64rem) so they follow the reader's font size; custom properties cannot be used inside @media, so values are repeated there by convention.

Columns, gutters, margins

Resize the window: the grid below reads --layout-columns, --layout-gutter and --layout-margin live.

123456789101112
  • Margin: viewport edge to content (--layout-margin): 20px, 32px from 640px.
  • Gutter: space between columns (--layout-gutter): 16px, 24px from 640px.
  • Container: .container caps at --layout-container-max (1280px); .container--narrow at --layout-container-narrow (42rem) for settings and request detail; .container--form at --layout-container-form (72rem) for form pages with a preview column. Sections of running content cap at --layout-container-prose (48rem).
  • Card grids use fixed counts (.card-grid: 2 columns, 3 from 640px, 4 from 1024px; row gap 32px). Directory groups are 1 column, 2 from 768px, 3 from 1024px. The product scroller shows 44%-wide items on phones and becomes a 3-column grid from 640px and 5 columns from 1024px. Page sections sit 56px apart (.section); .section--ruled adds an ink-15% rule and 32px of padding. Generic grids use .grid--auto (minmax(18rem, 1fr)).

Usage

  • Sticky elements account for the top bar: top: calc(var(--layout-topbar-height) + var(--space-6)).
  • Phones reserve --layout-tabbar-height plus the safe-area inset at the bottom of body.
  • See Layout primitives for stack, cluster, grid and split.
