Layout

Five breakpoints, a 4/8/12-column grid, gutters and margins that grow with the viewport, and the page templates the mocks use.

WCAG 2.2 AAMobile first
  • Overview
  • Breakpoints

Overview

Mobile first. Base styles target 360px; breakpoints add columns, gutters and margins through tokens, so components read --layout-* instead of writing their own media queries. Queries use min-width in rem (48rem, 64rem) so they follow the reader's font size; custom properties cannot be used inside @media, so values are repeated there by convention.

Columns, gutters, margins

Resize the window: the grid below reads --layout-columns, --layout-gutter and --layout-margin live.

123456789101112
  • Margin: viewport edge to content (--layout-margin).
  • Gutter: space between columns (--layout-gutter).
  • Container: .container caps at --layout-container-max (1280px); .container--narrow at 42rem for forms.
  • Product grids use fixed counts (2/3/4 via .card-grid); generic grids use .grid--auto (minmax(18rem, 1fr)).

Usage

  • Sticky elements account for the top bar: top: calc(var(--layout-topbar-height) + var(--space-6)).
  • Phones reserve --layout-tabbar-height plus the safe-area inset at the bottom of body.
  • See Layout primitives for stack, cluster, grid and split.
