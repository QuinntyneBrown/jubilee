Iconography

A 24-unit, 2px-stroke line icon set in currentColor, with 47 icons: the 46 the mocks draw and the crossed eye that hides a password.

Overview

One line-icon set drawn on a 24-unit grid with a 2px round-capped stroke in currentColor, so an icon always matches the text beside it. Icons are inline SVG with class="icon"; there is no icon font.

Each icon means one thing everywhere (3.2.4): the circled tick is always verified, the heart always save.

The eye is the one icon with a partner. eye shows something: a preview of a listing, a password as typed. eye-off hides it again and is drawn in the same style: the eye with a stroke across it. The show-password button of the Text field swaps the two and changes its name with them, “Show password” then “Hide password”; no mock draws the pressed state.

Google's “G” in the Google Button is not part of this set. It is Google's mark, in Google's four colours, and is never redrawn as a line icon.

Sizes

.icon--sm 16px · .icon 20px · .icon--lg 24px. Buttons size icons at 1.25em of the label.

Labelling and usage

  • Decorative icons next to text: aria-hidden="true", no title.
  • Icon-only controls: the control carries aria-label ("Save Luzandre.com"); the SVG stays hidden.
  • Status icons pair with words; an icon alone never carries meaning (1.4.1). The verified tick carries visually hidden "Verified".
  • Meaningful icons meet 3:1 against their background (1.4.11); the verified green is checked in contrast-pairs.json.
  • Media tiles use the same icons at 28% width with a 1.25 stroke as photo stand-ins; see Media tile.
