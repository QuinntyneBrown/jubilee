Start here

The Jubilee design system is the visual and interaction language of Jubilee, Toronto's Christian marketplace, written down once so every screen built in the Angular app is consistent. It was extracted from the 271 HTML mocks in docs/mocks: every token traces to a mock or a logged correction, both themes pass WCAG 2.2 AA, and every component documents anatomy, variants, sizes, states, responsive behaviour, accessibility, content and code.

How to use

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">

<button class="btn btn--primary" type="button">Book a meeting</button>
  • Link the CSS. tokens/tokens.css first, then assets/components.css. assets/ds.css and ds.js are only for these docs.
  • Use the classes. Each component page's Code section lists the classes and attributes; states come from native attributes (disabled, aria-invalid, aria-current, aria-pressed, aria-busy).
  • Consume tokens. Generate platform constants from tokens/tokens.json (DTCG). Never copy a raw value.
  • Theme. Set data-theme on <html>, or let the OS decide. See Theming.
  • Change the system. Edit tokens.css or components.css, run the contrast and structure checkers, re-export tokens.json, and log the change in the README.
