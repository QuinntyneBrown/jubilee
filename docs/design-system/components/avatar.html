Avatar

Avatars put a face, or at least initials, beside a name: the businesses in your messages, the members asking for quotes, you in the top bar. In the mocks they are always initials.

Overview

Use an avatar next to a person’s or business’s name in rows, threads, dialogs and the top bar. It never stands alone as the only name, except as the account menu trigger, where it is a link with an aria-label. For a business’s logo or product image use a Media tile.

  • Default (.avatar): gold-subtle circle with accent initials, for other people and businesses.
  • Brand (.avatar--brand): green solid with inverse semibold initials, reserved for the signed-in member (Joanna Adeyemi, "JA") so "you" is always recognisable.
  • Photo: an <img> inside the circle, cropped with object-fit: cover; falls back to initials when it fails.
  • Group (.avatar-group): overlapping avatars ringed in the surface colour, for "3 people from Grace Toronto Church".

Anatomy

  1. Initials or imageUp to two letters in --text-label, accent on accent-subtle; or an image filling the circle.
  2. ContainerCircle (--radius-full) at --avatar-size-sm/md/lg, flex: none so it never squashes in a row.

States

Avatars are usually decorative and have no states. When one is a link (account menu) it has default, hover, focus and active; hover and active do not change its look, the cursor and focus ring do the work. Loading uses a skeleton circle.

Responsive behaviour

  • Sizes do not change with the viewport. Rows keep 40px avatars at 360px; the top bar keeps 32px.
  • The account avatar in the top bar is desktop only (.only-desktop); on phones the You tab in the tab bar replaces it.
  • Avatars are flex: none: the name beside them wraps or truncates, the circle never shrinks.

Theming

Default reads --color-accent-subtle and --color-fg-accent; brand reads --color-success-solid and --color-fg-inverse. Both are re-mapped in dark mode and keep 4.5:1 initials.

.avatar { background: var(--color-accent-subtle); color: var(--color-fg-accent); }
.avatar--brand { background: var(--color-success-solid); color: var(--color-fg-inverse); }

Accessibility

Role and pattern

A decorative <span aria-hidden="true"> when the name is already beside it (almost always). A link (<a>) with aria-label when it is the account menu trigger; see the APG link pattern. A group with no visible names is role="img" with an aria-label.

Keyboard

KeyAction
TabReaches only linked avatars.
EnterFollows the link (opens the account menu).

Focus

Linked avatars take the shared focus ring, offset 2px around the circle.

Labelling

Hide decorative avatars (aria-hidden="true") so names are not read twice ("SP Samuel Park"). Images inside avatars use alt="" for the same reason. Linked avatars say what they open: "Account menu for Joanna Adeyemi".

Motion

None. Skeleton avatars shimmer and stop under reduced motion.

Touch

The 32px account avatar is above the 24px minimum and sits 16px from its neighbours in the top bar. Use the medium size if an avatar is ever the only target in a row.

Content

  • Initials are the first letters of the first two words: "Legacy Financial" → LF, "WaterWorks Plumbing & Drains" → WW, "Joanna Adeyemi" → JA.
  • Use one letter for one-word names ("Luzandre.com" → L) rather than inventing a second.
  • Never use an avatar for status. Unread is shown with a dot or a badge next to the name.
