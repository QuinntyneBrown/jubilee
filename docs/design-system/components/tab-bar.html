Tab bar

On phones the top bar drops its links and the tab bar takes them: Browse, List, Messages and You, always one thumb away at the bottom of the screen.

Overview

The tab bar is the phone form of the primary navigation in the Top bar. It is not a set of Tabs: each item is a link to a separate page, and the current one carries aria-current="page". It appears below 768px on every page that has a top bar, and never on auth, error or system pages.

  • Four items, always the same four, in the same order: Browse, List (list your business), Messages, You (account).
  • The current item gets a gold pill behind its icon and a semibold label.
  • Messages carries an unread .badge--count at the icon's top-right.

Anatomy

  1. Indicator pillIcon padded --space-1 / --space-4 in a --radius-full pill, filled --color-accent with an ink icon on the current item.
  2. LabelOne word, --text-caption; semibold and --color-fg-default when current, --color-fg-muted otherwise.
  3. Count badge.badge--count positioned at the icon's top-right; the number is hidden from assistive tech and spoken as ", 2 unread".
  4. Container.tabbar: fixed to the bottom at --z-sticky, equal columns, surface background, hairline top border, bottom padding for the safe area. Items are --layout-tabbar-height tall.

Variants

There is one tab bar. The only thing that changes is which item is current.

Sizes

One size: items are --layout-tabbar-height tall and share the width equally.

States

Items are links. Hover and focus are forced with data-state; there is no disabled item, because every member can reach all four destinations (signed-out members are sent to sign in).

Responsive behaviour

  • Shown only below 768px (--layout-breakpoint-md); from 768px the top bar's links replace it.
  • While it shows, body:has(.tabbar) gets bottom padding of --layout-tabbar-height plus the safe-area inset, and the toast region moves up by the same amount.
  • At 360px each item is 90px wide; labels never wrap. A fifth destination does not fit and does not belong here.
  • Dialogs that become bottom sheets on phones cover the tab bar (--z-modal is above --z-sticky).

Theming

Surface, border and label colours flip with the theme. The current pill stays gold with an ink icon in both themes (--color-fg-on-accent on --color-accent), so the selected destination is the brightest thing on the bar in light and dark.

Accessibility

Role and pattern

A <nav aria-label="Primary, phone"> of links with aria-current="page" on the current one. It is navigation, not the APG tabs pattern: do not use role="tablist". See landmark regions.

Keyboard

KeyAction
TabReaches the items last on the page, after the footer, in visual left-to-right order.
EnterFollows the link.

Focus

The shared 2px --color-focus-ring around the item. Because the bar is fixed, pages set scroll-padding-bottom to its height so focused content is never hidden behind it (2.4.11).

Labelling

Each item's name is its visible one-word label; icons are aria-hidden. The count is appended as visually hidden text: "Messages, 2 unread". The landmark label differs from the top bar's "Primary".

Motion

No motion: the bar does not animate in, hide on scroll or slide the pill between items.

Touch

Each item is at least 90px wide and --layout-tabbar-height tall, well above the 44px comfortable target; items touch edge to edge, so the whole cell is the target.

Content

  • One-word labels: Browse, List, Messages, You. "You" rather than "Account" or "Profile" because it holds profile, saved, requests and settings.
  • Never put an action ("Sign out") or a filter in the tab bar.
  • Counts cap at 99 and show "99+".
