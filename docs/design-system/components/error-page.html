Error page

When a whole page cannot be shown, Jubilee says why in plain words, reassures that nothing is lost, and offers the one way forward. Six screens share one shape: an empty state centred in a status page.

WCAG 2.2 AAStatus: stable.status-page + .empty6 status mocks

Overview

Use an error page when the route itself fails. For a region that fails to load inside a working page, use an Empty state with .empty--error; for a lasting condition while the page still works (slow or offline with a cache), use a banner.

  • In-app (404 not found, 403 forbidden): inside the normal top bar, footer and tab bar, so the person can navigate away. main.container.page > .status-page > .empty.
  • Bare (500 server error, offline, maintenance, session expired): the app shell may be unavailable, so the page uses the default Auth layout: logo, then the empty state in an .auth-card. main.auth-layout > .auth-card.card > .empty.

Anatomy

  1. Icon discNames the kind of failure at a glance: compass (lost), lock, warning, wifi-off, gear, clock.
  2. Title<h1 class="empty__title"> on the real page: what happened.
  3. Reassurance.empty__text: what is safe and what to do.
  4. ActionsOne primary way forward, optionally one way out.
  5. ReferenceServer errors only: .text-caption with a code to quote to support.

  • Offline retries automatically when the browser fires online, and Try again re-requests now.
  • Maintenance rechecks every minute; the time is the real end time, not "soon".
  • Session expired returns to the requested page after sign-in, with drafts restored.
  • Disabled does not occur: every error page has at least one working action.

Responsive behaviour

  • Centred at every width. At 360px the auth card fills the width minus --layout-margin; actions wrap to two centred rows.
  • In-app error pages keep the phone tab bar, so Browse, Messages and You stay one tap away.

Theming

No component tokens of its own: the page uses --color-bg-canvas, the card --color-bg-surface and the empty state's disc tokens. Error pages keep the gold disc rather than the danger one: they are a dead end, not an alarm.

Accessibility

Role and pattern

A normal page: one <h1> (the empty title), a <main> landmark and a <title> that starts with the error ("Page not found · Jubilee"). Serve the right HTTP status (404, 403, 500, 503). No live region is needed because it is a page load. See the APG landmark regions practice.

Keyboard

KeyAction
TabSkip link, then (in-app) the top bar, then the actions.
EnterActivates the focused action.

Focus

Focus starts at the top of the document like any page. If an error page replaces content client-side, move focus to its <h1>.

Labelling

The heading says what happened; the icon is decorative. The reference code is plain text that can be selected and copied.

Content

  • Say what happened in the person's terms: "We can’t find that page", "You’ve been signed out". Not "404" or "Unauthorized".
  • Take the blame when it is ours: "Something went wrong on our side".
  • Reassure with specifics: "Your messages and requests are safe", "drafts are kept", "back by 6:00 a.m. Eastern on Wednesday 11 November".
  • One primary action that fixes it (Try again, Sign in), one that leaves (Back to browse, Get help).
