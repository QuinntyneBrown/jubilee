Textarea

A textarea takes more than a line: a message to a business, the About on a listing, a note with an order. It grows vertically, never sideways.

Overview

Use a textarea when the answer is a sentence or more. For a single line use a Text field. It shares the field tokens and states with the text field and lives in a Form field.

  • Standard: 2–5 rows by content: address 2, note 3, About 4, first message 5.
  • With counter: when there is a hard limit, the counter sits under it and counts down.
  • Composer: the one-row textarea in a conversation (.composer), with a hidden label and an icon Send button; see Message thread.

Anatomy

  1. LabelVisible label with marker.
  2. Text area.textarea: same edge, fill and radius as .input; minimum 2.5 × 44px.
  3. Resize handleVertical only (resize: vertical).
  4. Counter.field__counter, linked by aria-describedby.

Sizes

Size by rows, matched to the answer you expect. Width always fills the form column.

The CSS minimum is calc(var(--control-height-md) * 2.5), about 2 rows.
HTML
<textarea class="textarea" rows="2" aria-label="Two rows">2 rows · address</textarea>
<textarea class="textarea" rows="3" aria-label="Three rows">3 rows · note, report</textarea>
<textarea class="textarea" rows="5" aria-label="Five rows">5 rows · first message</textarea>

Responsive behaviour

  • Full width of the form column at every breakpoint; rows stay the same, so the field gets taller as the column narrows.
  • In a phone dialog sheet the body scrolls and the footer stays visible; a long textarea never pushes Send off-screen.
  • The composer is pinned to the bottom of the conversation on phones, above the tab bar.

Theming

Reads the same --field-* component tokens as .input; override them on a parent to re-skin both. The composer removes the resize handle and drops the minimum height to --control-height-md.

Accessibility

Role and pattern

Native <textarea>. No APG pattern applies beyond a labelled form control; the APG names and descriptions practice covers the label and description wiring.

Keyboard

KeyAction
TabMoves in and out; Tab never inserts a tab character.
EnterNew line. In the composer, Enter sends and Shift+Enter adds a line, stated in the help for first use.

Focus

Same ring as the text field: 2px --color-focus-ring at zero offset with a matching border.

Labelling

Visible label (hidden only in the composer, where the thread heading gives context). Help, error and counter in aria-describedby. The counter's live updates go to a polite live region at most once a second, not on every keystroke.

Motion

Border transition over --duration-fast, zeroed under reduced motion. The composer's growth is instant.

Touch

At least 2.5 × 44px tall; the resize handle is a convenience, never the only way to see the text (the field scrolls).

Content

  • Label says what to write (“What would you like to talk about?”, “Tell us what happened”).
  • Help gives the reader of the message: “Be specific and Trevor can answer in one reply.”
  • Pre-fill only when editing; never pre-fill a message on the member's behalf.
  • Counters read “53 / 300”.
