Layout primitives

Layout primitives are the handful of classes that place everything else: a centred container, vertical stacks, wrapping clusters, the column grid, a main-and-aside split, the card grid and the page and section heads. They hold no colour and no content of their own.

Overview

Every Jubilee page is a .container with a .page-header, then sections laid out with these classes. Use them instead of inline flex or grid styles; they read the Layout and Spacing tokens, so a change of gutter or margin lands everywhere. See Navigation and page structure for how they compose into page templates.

Anatomy

  1. Page header.page-header: title block and an action cluster, wrapping, --space-6 above and below.
  2. Actions.cluster: wrapping row, --space-3 gap.
  3. Section head.section-head: h2 and a link on one baseline, --space-4 below.
  4. Split.split: one column, then 1.6 : 1 (or even) from 1024px with --space-10 between.

States

Layout primitives are not interactive and have no states; the components placed in them carry their own.

  • Breakpoints are 640, 768 and 1024px (--layout-breakpoint-sm/md/lg). Media queries use rem (40rem, 48rem, 64rem) so they follow text zoom.
  • Every grid child gets min-width: 0 so long names wrap instead of pushing the page sideways at 360px.
  • Clusters wrap; nothing in a layout primitive scrolls horizontally except the explicit .scroller and .chip-row.

Theming

Layout primitives use spacing and layout tokens only, no colour, so they are identical in both themes. The grid demo's tint is documentation chrome.

Accessibility

Role and pattern

Layout classes add no semantics. Put them on the element that is already right: <main class="container">, <ul class="card-grid"> for lists of cards, <section> with a .section-head heading. Follow the APG landmark regions guidance.

Keyboard

KeyAction
TabFollows DOM order. Never reorder with CSS (order, grid placement) so that visual order and focus order differ.

Focus

No focus of their own. Sticky asides (.split__sticky) stay below the top bar so a focused control is never hidden under it (WCAG 2.4.11).

Labelling

A section with a .section-head is named by its heading (aria-labelledby). The page header holds the only h1.

Contrast

Motion

None. Layout never animates; reduced motion has nothing to remove.

Touch

Cluster and stack gaps (at least --space-2) keep neighbouring 24px targets from touching; the card grid's --space-4 column gap does the same for cards.

Content

  • Page titles are the thing's name ("Luzandre.com", "Help"); subtitles add one fact ("Verified · live since June 2026").
  • Section heads are short and the link says where it goes: "Needs your reply" / "All requests".
  • One page header per page; sections below use section heads.
