Sidebar navigation

The sidebar lists every section of a workspace down the left edge. It ships in the Jubilee component kit, but no mock uses it yet: My business and Account use tabs today. It is documented here as a core component so a future back office has a ready, accessible answer.

Overview

Honest status: .sidebar, .sidebar__group and .sidebar-layout exist in components.css, but none of the 272 mocks use them. The two places with section navigation, My business (5 sections) and Account (4 sections), use Tabs as page navigation, which is the right choice for five or fewer sections.

Reach for the sidebar when a workspace grows past what one tab row holds: more than six sections, sections in groups, or an admin tool used for hours at a desk (a future verification and moderation console for Miriam Castillo's team is the likely first case).

  • Grouped: overline group labels (.sidebar__group) over .nav-links. The current link gets a --color-bg-subtle pill and ink text.
  • Drawer below 1024px: the sidebar is hidden and opened from a .topbar__menu button, setting data-open="true". Use the Drawer behaviour for focus and dismissal.

Anatomy

  1. Group label.sidebar__group: --text-overline, uppercase, --color-fg-subtle. Names the workspace or a group.
  2. Current link.nav-link[aria-current="page"]: --color-bg-subtle pill with a --color-fg-default label.
  3. LinkFull-width .nav-link: icon, label, optional count badge; 40px tall (--control-height-md), 16px side padding, --radius-full pill, 14px medium --text-label.
  4. Container.sidebar: surface, hairline right border, --space-4 padding, --layout-sidebar-width wide, sticky full height from 1024px.

Variants

One visual form, with or without group labels. Icons are optional but all-or-nothing within a sidebar.

Responsive behaviour

  • From 1024px (--layout-breakpoint-lg) the sidebar is a sticky, full-height column inside .sidebar-layout.
  • Below 1024px it is display: none until opened; .topbar__menu (an icon button with aria-expanded and aria-controls) is shown only then.
  • On phones the tab bar still carries the four primary destinations; the sidebar never replaces it.

Theming

Surface tokens only, so it flips with the theme. The current pill uses --color-bg-subtle (ink 5% in light) with --color-fg-default, the same look as a hovered link, so aria-current="page" carries the state for assistive tech.

Accessibility

Role and pattern

A labelled <nav> of links with aria-current="page". Not a tree or menu. Group labels are plain text; if groups get long, wrap each in a <ul aria-labelledby> pointing at its label. See APG landmark regions; the drawer form follows the disclosure pattern.

Keyboard

KeyAction
TabMoves through the links in order.
EnterFollows the link.
Esc (drawer)Closes the drawer and returns focus to the menu button.

Focus

The shared ring around each link. When the drawer opens, focus moves to the current link; when it closes, back to the menu button.

Labelling

Label the landmark with the workspace ("Business sections"), distinct from "Primary". Counts are visually hidden text ("Requests, 3 open").

Motion

Link colour and fill transition over --duration-fast (150ms). The drawer slides in over --duration-slow (300ms); both zero under reduced motion.

Touch

Links are full width and 40px tall (--control-height-md) with --space-1 between them. On coarse pointers each gets an invisible hit area at least 44px tall (--target-comfortable).

Content

  • Section names are nouns that match the page titles: Overview, Listing, Products, Services, Requests.
  • Group labels name the workspace (the business name) or a category (Account); keep them to two or three words.
  • No more than about ten links; past that, the information architecture needs work.
