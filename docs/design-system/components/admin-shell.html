Admin shell

Overview

The frame of every screen of the admin application (L2-188, L2-272): the ink top bar, the sidebar of tables and the main column, which alone scrolls. It is not the app's Top bar or Sidebar navigation: the admin application is its own application at admin.jubilee.to, for the Jubilee team only, with a staff session of its own (ADR 0040).

Five blocks make it: .admin-app (the frame), .admin-top (the bar), .admin-nav (the sidebar of tables, a disclosure per group), .admin-page (a screen's width and padding) and .admin-heading (a screen's eyebrow, title and lead). Below 1024px the sidebar opens in the Admin tables drawer; ⌘K opens the Command palette.

Page width

.admin-page is 75rem wide for the overview, --wide (87.5rem, and room below for the Bulk bar) for a table and --record (less padding above) for a record.

Sizes

One size. The bar is --layout-topbar-height tall; the sidebar is 16rem wide in the frame and 18rem in the drawer; its items are --control-height-sm tall, its group buttons --target-min.

States

Sidebar items and group buttons have default, hover, focus and current (aria-current="page") or expanded (aria-expanded="true"). Hover is forced here with data-state.

Group

The bar's controls take the ring for dark surfaces, --color-focus-ring-on-brand. The jump brightens its text on hover. Loading, empty and error belong to the screen inside the shell (Work queue, Records table, Record), never to the shell, which stays put.

Responsive behaviour

  • From 1024px (--layout-breakpoint-lg) the sidebar stands beside the main column and the menu button hides. Below it the sidebar is the Admin tables drawer, opened by the menu button.
  • From 768px the jump is a field-like button up to 28rem wide; below, the round search button opens the same palette.
  • From 640px the environment ("admin.jubilee.to" and its badge) shows, and the bar's side padding grows from --space-4 to --space-6.
  • The page padding is --space-4, --space-6 from 640px and --space-10 from 1024px. At 360px the bar holds the menu, the lockup, search and the avatar; nothing overflows (L2-188 AC6).

Theming

The bar is the brand ink in both themes and reads every colour by role (--color-bg-brand, --color-fg-on-brand, --color-fg-on-brand-muted, --color-border-on-brand); the sidebar and main column sit on --color-bg-canvas, and the current item is the inverse ink.

Accessibility

Role and pattern

The bar is the page's header; the sidebar is a nav named "Tables"; the main column is main, reached by the skip link. Each group is a disclosure: a button with aria-expanded and aria-controls over a list that is hidden when closed. The screen open is marked aria-current="page", never by colour alone.

Keyboard

KeyAction
Tab / Shift+TabMoves through the bar, then the sidebar, then the screen, in reading order.
Enter, Space on a groupOpens or closes it.
⌘+K / Ctrl+KOpens the command palette from anywhere in the application.

Labelling

  • Each count says what it counts: "2.4k" reads "2,418 records" (aria-label).
  • The lock on a read-only group is an image named "Read-only".
  • The avatar is an image named with the staff member and their role ("Ada Nwosu, Moderator"); the menu that ends with "Sign out" opens from it (L2-188 AC3).
  • The menu and search buttons are icon buttons named "Open tables" and "Search".

Touch

Bar buttons are --target-comfortable (44px). Sidebar items are --control-height-sm and group buttons --target-min (24px), within WCAG 2.2 target size (2.5.8) for a staff tool used mostly with a pointer; in the drawer on a phone the same rows apply.

Motion

The group chevron turns in --duration-fast; the drawer slides in with slide-in-left. Both stop under prefers-reduced-motion, as every animation of the kit.

Content

  • The product name is "Admin" beside the lockup; the wordmark stays lowercase "jubilee".
  • Sidebar labels are the tables' plural names in sentence case ("Listing reports"); groups are their area ("Moderation", "Site & content").
  • Counts are abbreviated past 999 ("2.4k", "48k") and spelt out in the accessible name.
  • The greeting says the day, the staff member's first name and how many things are waiting: "Good morning, Ada. 14 things are waiting on staff."
  • The environment names the address and says "Production" in the danger badge, so nobody mistakes it for a test copy.
