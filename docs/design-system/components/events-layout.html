Events layout

The frame of /events: the ink Hero band with the where filter and the topic chips, then the list (“Next up · {n} events”, the feature card, the days, the note) beside a 300 px side column that stays in view from 1024 px.

Overview

  • The hero is the screen’s h1 (“What’s on in Toronto, and online.”) and holds the filters; the list never repeats them.
  • The filters change the list without a page load and write ?where=…&topic=… to the address (L2-301 AC3, AC4).
  • Loading, empty, no-results and error states replace the main column only; the hero, the filters and the side column stay (L2-303).

Anatomy

  1. Hero.hero: heading and line on ink.
  2. Where.segmented-choice--on-brand, a radio group named “Where”.
  3. TopicA .chip-row of toggle chips named “Topic”.
  4. Count.events-layout__count: “Next up · 9 events”, an h2 that takes focus after “Show everything”.
  5. Feature cardAn Event feature card.
  6. DaysEvent rows by day.
  7. Note.events-layout__note.
  8. Side column.events-layout__aside: You’re going and Running something?.

Responsive behaviour

  • Under 768 px: the where filter takes the full width, its three options sharing it equally, and the topic chips scroll sideways inside the hero (L2-301 AC2, L2-314 AC1).
  • From 768 px: the where filter shrinks to its content and the chips sit beside it (.event-filters turns to a row, --space-8 apart).
  • Under 1024 px: one column; “You’re going” and “Running something?” follow the list.
  • From 1024 px: the list beside a 300 px side column, which is sticky under the top bar (--layout-topbar-height + --space-6).

Theming

The hero is ink in both themes (the brand group of tokens); the main and side columns sit on the canvas. Shown one above the other: the where filter is as wide as its options from 768 px and does not fit half the column.

Accessibility

Landmarks

The side column is an <aside> named “Your events and hosting”. The count is the list’s h2, with tabindex="-1" so “Show everything” can move focus to it (L2-303 AC1).

Filters

Keyboard

Reading order is the hero, the filters, the list, then the side column, at every width.
