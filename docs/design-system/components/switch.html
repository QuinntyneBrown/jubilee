Switch

A switch changes a setting the moment it is flipped, like the e-mail notifications in settings. There is no Save button; an inline status says it saved.

WCAG 2.2 AAStatus: stablerole="switch" on a checkboxNotification settings

Overview

Use a switch for a setting that takes effect at once and that members expect to flip back and forth. If the change waits for a Save button, use a Checkbox. If it needs confirmation, it is not a switch.

  • Settings row: title and meta in the row body (the label), switch at the end (notification settings).
  • Inline: label.switch with the text beside the track, for a single setting in a card.

Anatomy

  1. Title.row__title inside the label for; the accessible name.
  2. Meta.row__meta, part of the label, explains what the setting does.
  3. Track44 × 24px (--target-comfortable × --target-min); --color-border-strong off, gold with an accent-border edge on.
  4. Thumb20px circle (--icon-size-md) on --color-bg-surface with --shadow-1; slides 20px.

Sizes

One size only: the 44 × 24px track meets the touch target on its own, and a smaller switch would not.

States

Forced with data-state. Hover changes only the cursor today (a hover edge is proposed). Active keeps the hover look; the thumb moves on release.

Responsive behaviour

  • The switch stays at the row's end at every width; the row body wraps.
  • Rows keep a 44px minimum height on phones, so the whole row is a comfortable target through the label.

Theming

On: --color-accent track with a --color-accent-border inset edge (gold alone is 1.6:1 on cream; the edge carries the 3:1). Off: --color-border-strong track. Thumb: --color-bg-surface with --shadow-1 in both themes.

Accessibility

Role and pattern

<input type="checkbox" role="switch">: native checkbox behaviour announced as a switch, on/off. See the APG switch pattern.

Keyboard

KeyAction
TabMoves to each switch.
SpaceFlips it. (Enter does not; this is native checkbox behaviour.)

Focus

The shared 2px ring around the pill-shaped track.

Labelling

A label for covering title and meta, so the name is the title and the meta is read with it. Never put “on/off” text in the label; the state is announced. The status message is in a role="status" region.

Motion

Track colour and thumb slide over --duration-base; reduced motion zeroes both through the token. The saving dot's pulse stops under reduced motion.

Touch

Track is 44 × 24px; with the row label the target is the full row (at least 44px tall).

Content

  • Titles name the thing being switched (“New messages”), not the action (“Turn on new messages”).
  • Meta says exactly what happens when on: “One hour before a booking.”
  • Tell members what always happens regardless (“We always e-mail you about sign-in and security”) under the list.
