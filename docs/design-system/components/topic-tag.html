Topic tag

The topic of an event, said by its name beside an 8 px dot: Christian gold, Tech ink, Entrepreneur green. It sits above the title of the feature card and the event page, and beside the title in a row.

WCAG 2.2 AAStatus: newtopic-tagL2-302

Overview

  • One tag per event: an event has exactly one topic (L2-307 AC1).
  • It is not a filter and not a link; the topic chips in the hero filter (Events layout) do that.
  • The name is always shown. The dot only repeats it, so the topic is never said by colour alone (L2-314 AC3).

Anatomy

  1. Dot::before, 8 px (--space-2), --radius-full, coloured by --topic-tag-dot.
  2. NameThe topic, in caption type, semibold, --color-fg-muted.

Sizes

One size: caption type with an 8 px dot.

States

None: it is static. A topic with no modifier draws the gold dot.

Responsive behaviour

The tag never wraps (white-space: nowrap). In a row it moves under the title when the two do not fit on one line.

Theming

The dots follow the theme: gold stays gold, Tech turns cream on the dark canvas, green lightens. The name is muted text in both.

Accessibility

Plain text. The dot is generated content with no text, so assistive technology reads only the name. Because the name is always there, the dot’s contrast is decorative; the name’s is checked.

Content

  • One of three names, exactly: “Christian”, “Tech”, “Entrepreneur”.
  • No other word beside it: not “Topic:”, not a count.
