Chip

Chips are small pills people press to narrow what they see: a category, a filter like Emergency calls, a shirt size. The selected chip turns gold. Their static cousin, the tag, labels credentials such as CKA® · CFP® · CLU®.

Overview

Use chips for a short set of options that apply instantly: filters on a category page, categories on Browse, recent searches, suggested first messages, a size. Use a Button group for exclusive view toggles, Tabs for switching panels, checkboxes inside forms, and a Badge for status that cannot be pressed.

  • Filter chip: <button class="chip" aria-pressed> toggles a filter on and off. Several can be on at once. Grouped in role="group" with a label.
  • Link chip: <a class="chip"> navigates (categories on Browse, recent searches). The current one carries aria-current="page".
  • Action chip: a plain <button class="chip"> that does one thing, such as the suggested openers in an empty conversation ("Can we meet by video?").
  • Choice chip: a <label class="chip"> wrapping a visually hidden radio, for one-of-many choices like size S–2XL on an order request.
  • Removable chip: a chip with a .remove button, for applied filters that can be dismissed one by one.
  • Chip row (.chip-row): a list of chips that scrolls sideways on phones and wraps from 768px. .chip-row--plain drops the top margin.
  • Tag (.tag): a static, square-cornered label for credentials and memberships. Not pressable.

Anatomy

  1. Label--text-label, one to three words, sentence case.
  2. Remove button (optional)A 24px (--target-min) round button with a 16px close icon and an aria-label naming the filter.
  3. ContainerPill (--radius-full), 32px tall (--control-height-sm), hairline --chip-border, --space-3 padding.

States

  • Selected is gold (--color-accent) with ink text in both themes, matching the primary button; the gold edge (--color-accent-border) keeps the pill visible on cream.
  • No results: when the pressed filters return nothing, keep them pressed and offer "Clear filters" in the empty state, as Home & property / no-results does.
  • Disabled chips are rare; prefer hiding a filter that cannot apply. Link chips use aria-disabled="true" and drop the href.

Responsive behaviour

  • .chip-row scrolls horizontally below 768px (no scrollbar, items keep their width) and wraps from 768px. The row bleeds by --space-1 so focus rings are not clipped.
  • Filter chip groups are desktop only on category pages (.only-desktop); phones get a Filters · 3 button that opens the filters dialog, where the count matches the pressed chips.
  • Chip labels never wrap or truncate. If a label does not fit at 360px inside a scrolling row, that is fine; inside a wrapping cluster, shorten it.

Theming

Chips read four component tokens (--chip-bg, --chip-fg, --chip-border, --chip-bg-hover) that alias semantic tokens. The selected state overrides them to the accent set. Re-skin a chip by overriding the component tokens, not .chip.

.chip[aria-pressed="true"], .chip[aria-current="page"] {
  --chip-bg: var(--color-accent); --chip-bg-hover: var(--color-accent-hover);
  --chip-border: var(--color-accent-border); --chip-fg: var(--color-fg-on-accent);
}

Tags use --color-bg-surface, --color-border-default and --radius-md: square-ish corners tell people they are not pressable.

Accessibility

Role and pattern

Filter chips are toggle buttons (APG button pattern, aria-pressed) inside role="group" with aria-label="Filters". Link chips are links in a list with aria-current="page". Choice chips are native radios in a <fieldset> with a <legend> (APG radio group). Tags are plain text.

Keyboard

KeyAction
Tab / Shift+TabMoves through filter, link and action chips one by one; into and out of a choice group as one stop.
Enter, SpaceToggles a filter chip or activates an action chip. Enter follows a link chip.
← → ↑ ↓Inside a choice group, moves and selects the next size (native radio behaviour).
Enter on .removeRemoves that filter; focus moves to the next chip, or to the filter trigger when none remain.

Focus

Chips take the shared focus ring. Choice chips show the ring on the label when the hidden radio is focused. In a scrolling chip row the focused chip scrolls into view.

Labelling

The chip text is the name. Never put the state in the text ("Emergency calls ✓"); aria-pressed announces it. Remove buttons say what they remove: "Remove filter: Serves Scarborough". The filter group and the size fieldset are labelled.

Motion

Background transitions over --duration-fast; reduced motion makes it instant. The chip row scrolls with the page’s smooth scrolling, which is off under reduced motion.

Touch

Default chips are drawn 32px tall with 8px gaps, meeting the 24px target-spacing rule; small chips are 24px and need the same gaps. Remove buttons are 24px. In a scrolling row on phones, chips are spaced --space-2.

On a touch screen (pointer: coarse) a default chip is pressed over at least 44 × 44px (--target-comfortable, L2-162): an invisible hit area centred on the chip reaches 6px above and below it, and the chip is still drawn 32px tall. Chips that wrap onto several rows are set in a cluster, whose 12px gap keeps the hit areas of two rows from overlapping. Small chips keep their 24px target. See ADR 0060.

Content

  • Filters say what is kept, not removed: "Open Saturdays", "Free quote", "Serves Scarborough".
  • Categories use the directory names exactly: "Financial & insurance", "Legal & immigration". Use & as the mocks do.
  • Suggested openers are full questions a member would actually send, ending with a question mark.
  • Tags hold credentials as the business writes them: "CKA® · CFP® · CLU®".
