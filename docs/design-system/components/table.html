Table

Tables compare many records on the same columns: a business owner’s products, the admin verification queue. They are for owners and admins at desk width; members see cards and rows instead.

Overview

Use a table when people compare records across the same fields (price, status, request count) or scan a queue to pick the next one. If each record is read on its own, use a List of rows or cards; if you are showing one record’s fields, use a Description list.

  • Data table (.table in .table-wrap) is the only variant: a bordered, rounded surface with a sunken header row.
  • Numeric columns (.num) right-align with tabular figures so $34 and $2,400 line up.
  • Sortable columns put a <button> in the header and aria-sort on the <th>; only the column currently sorted carries the attribute.
  • Row actions are ghost icon buttons in the last column, named with the row ("Edit Gold cross stoneware mug").
  • Dense (.table--dense) halves the cell padding for admin screens with many columns.

Anatomy

  1. Header row<th scope="col"> on --color-bg-surface-sunken, label text in --color-fg-muted; sticky inside a scrolling wrap.
  2. Primary cellThe record’s name, optionally with a 48px .media--thumb in a .cluster. It is the row’s accessible identity.
  3. Numeric cell.num: right-aligned, tabular figures, prices in CAD ("$24", "$22 ea").
  4. Status cellA Badge in a tone; the word carries the meaning, colour only supports it.
  5. Row actionsGhost icon buttons (.btn--icon.btn--ghost.btn--sm) with an aria-label that names the row. The header cell is a visually hidden "Actions".

One table, two configurations seen in the mocks: an owner’s inventory with row actions, and an admin queue with a sorted column and linked names.

  • Loading: keep the header and render three to four skeleton rows (.skeleton--avatar plus two .skeleton--text), with aria-hidden="true" on the skeleton and aria-busy="true" on the region, as My products / loading does.
  • Empty and error: replace the whole table with an Empty state or Alert and banner, never a table with a single "No data" row.
  • Disabled does not apply to rows. Disable the row’s action buttons instead, and say why in the status badge.

Responsive behaviour

  • .table-wrap scrolls horizontally below the table’s natural width; the header stays sticky inside it. The page never scrolls sideways.
  • Keep the primary cell first so it is visible at 360px without scrolling; put the actions column last.
  • Owner tables stay tables on phones (they are short and scrolling reveals the actions). Member-facing collections use rows or cards at every width.
  • Row actions are always visible on touch devices (@media (hover: none)); on pointer devices .row-actions may reveal on hover and focus-within.

Theming

The table reads semantic surface tokens: --color-bg-surface for the body, --color-bg-surface-sunken for the header, --color-bg-subtle for hover and --color-accent-subtle for selected rows. Dark mode swaps those tokens; the table has no component tokens.

.table th { background: var(--color-bg-surface-sunken); color: var(--color-fg-muted); }
.table tbody tr[aria-selected="true"] { background: var(--color-accent-subtle); }

Accessibility

Role and pattern

Native <table> with <caption>, <thead> and <th scope="col">. Follow the APG table pattern and the sortable table example. Do not use role="grid": Jubilee tables are read, not navigated cell by cell.

Keyboard

KeyAction
Tab / Shift+TabMoves through the links, sort buttons and row actions in reading order.
Enter, SpaceOn a sort button, toggles the order and updates aria-sort. On a row action, activates it.
Screen-reader table keysUsers move by cell with their reader’s table commands; headers are announced because they use <th scope>.

Focus

Links and buttons inside cells take the shared focus ring. Focusing anything in a row also lights the row (:focus-within) and reveals hidden row actions.

Labelling

Every table has a <caption> (visually hidden when a heading already sits above it). Icon-only row actions name the action and the row. The actions header is a visually hidden "Actions", never empty.

Motion

Only the row-action reveal fades, over --duration-fast; reduced motion makes it instant through the token.

Touch

Row action buttons are 32px with 4px gaps; on touch they are always visible. Sort buttons fill the header label, which is at least 24px tall.

Content

  • Column headers are short nouns in sentence case: "Product", "Price", "Requests", "Stage". No units in cells when the header says them.
  • Prices are CAD with no decimals for whole dollars ("$34"), "ea" for per-item prices, and "Ask" when there is no fixed price.
  • Dates are relative when recent ("Today, 9:40 a.m.", "Yesterday") and then short ("Sat 7 Nov").
  • Status cells use one or two words: "Listed", "Sold out", "Declined". Explain a status elsewhere, not inside the badge.
