Included chips

Overview

The fixed set of L2-199 AC3: Utilities, Wi-Fi, Laundry, Furnished, Parking, Private bath, Kitchen use, Pets OK. The chosen ones appear on the space page as the included list.

The block is Chip; this page records how rooms and rentals uses it. Everything not said here follows that page.

As Chip.

Four chosen for the Annex basement.

Sizes

One size, the default of Chip.

States

The states of Chip: default, hover, focus, active, pressed or checked, disabled.

Responsive behaviour

Wraps onto more lines on a phone; the chip row scrolls sideways under 768px and wraps from 768px.

Theming

Inherits Chip's tokens in both themes.

Accessibility

Role and pattern

Toggle buttons (APG button, toggle) in a <fieldset> with the legend "What’s included"; each pressed state is carried by aria-pressed.

KeyAction
TabMoves between the chips.
Enter / SpaceToggles the chip.

Focus

Shared ring.

Labelling

Each chip's text is its name.
