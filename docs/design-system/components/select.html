Select

A select picks one value from a list too long to show as radios: a category, which service to book, how often to e-mail. Jubilee uses the native control with its own edge and chevron.

Overview

Use a select for 6 or more options, or fewer when space is tight and the default is usually right. For 2–5 options members should compare, use a Radio group. For commands, use a Menu. Jubilee never builds a custom listbox: the native picker is accessible and familiar on phones.

  • In a form: full width under a label (Category, Service, Pricing).
  • Inline sort: small, auto width, label beside it (category page Sort).
  • Settings: constrained width so the chevron stays near the value (digest frequency).

Anatomy

  1. LabelVisible <label for>.
  2. ValueSelected option text in --text-body; padding leaves --space-10 for the chevron.
  3. ChevronDrawn with two gradients in currentColor, so it follows the text colour in both themes and in disabled.

Sizes

The input size modifiers apply: .input--sm, default, .input--lg. .select--fit makes a select as wide as its longest option, for one that stands beside a button and not in a field: the switcher between an owner’s businesses on My business (<select class="select input--sm select--fit">).
HTML
<select class="select input--sm" aria-label="Small select" style="width: auto;"><option>Small · 32px</option></select>
<select class="select" aria-label="Medium select" style="width: auto;"><option>Medium · 44px</option></select>
<select class="select input--lg" aria-label="Large select" style="width: auto;"><option>Large · 48px</option></select>

States

Forced with data-state. Active shows focus. Open is the platform picker and is not styled. Read-only does not exist for selects; use disabled plus a hidden input, or show the value as text.

Responsive behaviour

  • Full width in forms; the two-column grid stacks under 640px.
  • On phones the native picker (wheel or sheet) replaces the dropdown automatically.
  • Inline sort stays inline at 360px; on the category page it shares a row with the Filters button and wraps under it if needed.

Theming

Shares the --field-* tokens with the text field. The chevron is currentColor, so it changes with --field-fg and turns --color-fg-disabled when disabled. Set color-scheme on the theme root so the native option list follows dark mode.

Accessibility

Role and pattern

Native <select>; it exposes the semantics of the APG listbox pattern (collapsed combobox) without custom script.

Keyboard

KeyAction
TabMoves to the select.
↑ / ↓Change the value (Windows) or open the list (macOS).
Space / Alt+↓Open the list.
Letter keysJump to the next option starting with that letter.
EscCloses the list without changing.

Focus

Same ring as text fields: 2px --color-focus-ring at zero offset.

Labelling

Visible label with for. Option text is self-contained (“Discovery meeting · 30 min · Free”). A sort select that applies immediately announces the new result count in a polite live region.

Motion

Border transition over --duration-fast; the native list's animation belongs to the platform.

Touch

44px tall by default; the small sort select is 32px and only appears with 8px clear around it.

Content

  • Options are short and parallel; put the most common first or select it by default.
  • No “Please select” placeholder option when a sensible default exists; when one is needed, use “Choose a category” and make it invalid on submit.
  • Sort labels: “Recommended”, “Newest”, “Name A–Z”.
