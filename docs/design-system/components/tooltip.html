Tooltip

A tooltip names or briefly explains a control when it is hovered or focused. It ships in the kit, but no mock uses it: Jubilee's icon buttons rely on aria-label and their context. Add tooltips to icon buttons whose meaning is not obvious, never to carry information.

Overview

Use a tooltip to show the visible name of an icon-only button (the edit and delete icons in the products table) or a short extra hint on a control. Do not use one for anything a person needs to complete a task, for interactive content (use a Popover), or on touch-first screens where hover does not exist. Never put a tooltip on disabled controls: they cannot be focused.

  • Label: repeats the icon button's name visually; the tooltip is aria-hidden because aria-label already carries the name.
  • Description: adds a hint to a control that already has a name; give the tooltip role="tooltip" and an id, and point to it with aria-describedby.

Anatomy

  1. Bubble.tooltip: --color-bg-inverse, --color-fg-inverse text in --text-caption, --radius-sm, --shadow-2, padding --space-1 × --space-2.
  2. ArrowA CSS triangle in the bubble colour, --space-1 tall.
  3. TriggerAny focusable control inside .has-tooltip; the bubble sits --space-2 above it.

Sizes

One size: --text-caption on --space-1 × --space-2 padding. Tooltips are never enlarged; longer content belongs in a popover.

Responsive behaviour

  • Tooltips need hover or focus; on touch screens they appear only on keyboard focus. Anything a phone user needs must be visible without one.
  • The bubble does not wrap (white-space: nowrap); keep it to a few words so it fits at 320px.
  • Near a screen edge, move the bubble below or to the side rather than letting it clip.

Theming

The bubble uses the inverse pair: ink with cream text in light, cream with ink text in dark, at well above 4.5:1 in both. The arrow uses the same token so it always matches.

Accessibility

Role and pattern

role="tooltip" on the bubble, referenced by aria-describedby from its trigger, as in the APG tooltip pattern. When it only repeats an aria-label, mark it aria-hidden="true" instead so the name is not read twice.

Keyboard

KeyAction
TabFocusing the trigger shows the tooltip.
EscHides the tooltip without moving focus (WCAG 1.4.13); needs a small script.
Leaving the triggerHides it at once.

Focus

Focus stays on the trigger; the tooltip never receives focus. The trigger shows the shared focus ring.

Labelling

The trigger's name comes from its own aria-label or text, never only from the tooltip, so it still has a name if the tooltip fails to load.

Motion

Fades in over --duration-fast after a 300ms hover delay and hides at once. Reduced motion zeroes the fade; the delay stays, because it prevents flicker rather than decorating.

Touch

The trigger keeps its own target size; the tooltip adds none. Do not rely on long-press to show it.

Content

  • Two to four words, sentence case, no full stop: "Edit", "Delete", "Copy link".
  • Match the start of the button's aria-label.
  • No links, no keyboard shortcuts unless the app really has them, no essential information.
