Add to bag

The quantity and “Add to bag · $25”; once added, “Added to bag”, the line that was added and “Check out”.

WCAG 2.2 AAStatus: newadd-to-bagL2-265

Overview

  • Under the sizes. The amount on the button is the unit price times the quantity.
  • Pressing it with no size shows the size picker’s nudge instead.

Anatomy

  1. QuantityA Quantity stepper.
  2. ButtonInk (--color-bg-inverse), 56 px, the frame’s colour; the success colour with a check once added.
  3. Added line“{fit} {size} · Black” and “Check out”, which opens the bag; a status.

Sizes

One size, 56 px.

States

Button: default, hover, pressed (scaled to 98%, not under reduced motion), focus, added. Changing the fit, size or quantity returns it to “Add to bag”.

Responsive behaviour

The button takes the row beside the stepper at every width.

Theming

Ink on cream in light, cream on ink in dark; added is the success colour with the inverse text.

Both themes

1
1

Accessibility

The button’s text says the state (“Added to bag”), with a check icon; the added line is a status, so it is announced. Colour is never the only sign.
