Work queue

The overview of the admin application: what is waiting on staff, grouped, with the next record and how many wait; what the system needs; and the recent changes (L2-274, L2-275).

Overview

The overview of the admin application (L2-274, L2-275) says what is waiting on staff. .work-queue is one group of it ("Safety"): each line names a table, the next record waiting and how many wait, with the oldest's age. The line opens that first record; its count opens the table. Beside it, .admin-aside holds what the system needs (.system-list: failed jobs, retries, maintenance) and the recent changes (.change-list, the History entries of the audit log).

The counts and the "Next" line are read with the staff session when the overview opens; nothing polls or pushes (ADR 0058).

System line

system-list__item--bad (failed, gave up) takes the danger icon, --wait (retrying) the warning icon, and no modifier (maintenance) the muted one. The icon is named ("Failed", "Retrying"), so the tone never carries the state alone.

Sizes

One size. The count is --font-size-2xl in the display face; the grid gives the aside 20rem from 1024px.

Error

When the overview cannot be read, the greeting stays and an Empty state (empty--error, role="alert") says "We couldn’t load what is waiting on staff" with JB-ADM-503 and "Try again".

Responsive behaviour

  • Below 1024px the aside drops below the queue; from 1024px the grid is the queue and a 20rem aside.
  • Below 640px the age hides; the count and its accessible name stay.
  • The "Next" line truncates with an ellipsis on one line; the record opens in full.

Theming

Every colour is a role: the head's rule is --color-fg-default, lines are --color-border-default, urgent counts --color-danger-fg.

Accessibility

Role and pattern

Each group is a section named by its heading (aria-labelledby), with a list of lines. A line is two links: the record ("Listing reports, Next: …") and the table ("See all Listing reports, 2 waiting, urgent"). The aside is a complementary landmark named "System and recent changes".

Keyboard

KeyAction
TabMoves to a line's record link, then to its count, line by line.
EnterOpens the first record waiting, or the table.

Labelling

  • The count link's name says what the number means and whether it is urgent; colour never carries urgency alone.
  • System icons are images named "Failed", "Retrying" or "Maintenance".
  • Loading sets aria-busy="true" on the group.

Motion

The chevron nudges 2px on hover in --duration-fast; nothing moves under prefers-reduced-motion.

Content

  • Group titles are the kind of work ("Safety", "Waiting on us"); the note is the promise ("Answer within 24 hours").
  • A line's name is the table; "Next:" shows the record a moderator will open, quoted when it is what a member wrote.
  • Ages are short: "oldest 3h", "oldest 2d".
  • All clear: "No reports, alerts, listings or requests are waiting." Never a celebration; the tables still hold everything.
  • Reporters are never named in the queue (L2-105).
