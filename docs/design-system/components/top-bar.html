Top bar

The top bar is the first thing on every signed-in and public page: the jubilee wordmark, search, the two or three places a member goes most, and their notifications and account. In Jubilee it sits on the ink brand band.

Overview

Use the top bar once per page, as the page's banner landmark. It carries global navigation only; section navigation inside My business or Account uses Tabs, and phones get the Tab bar for the same primary destinations. Auth, error and system pages (sign in, sign up, verify email, 500, offline, maintenance) have no top bar: they sit in the Auth layout, where a single wordmark link is enough.

  • Ink (.topbar.topbar--ink) is the Jubilee bar and the only one the mocks use: ink background, cream wordmark in the display face with the gold mark, pill search, gold underline on the current link, ghost icon buttons and the gold unread dot.
  • Plain (.topbar) is the kit base: white surface, hairline bottom border, current link as an accent-subtle pill. No mock uses it on its own; keep it for embedded or back-office surfaces where the brand band would compete with content.
  • Signed out is the ink bar with Browse and Sign in links and a single gold Join free button instead of notifications and the avatar.

Anatomy

  1. Wordmark.topbar__brand: gold .brand-mark plus "jubilee" in --font-family-display, bold at 110% width, --font-size-2xl. Links home (Browse, or Welcome when signed out).
  2. Search.search inside a role="search" form, visually hidden label, pill input on --color-bg-on-brand-subtle. Shown from 1024px; below that an icon button opens the search page.
  3. Primary links.topbar__nav of .nav-links in a <nav aria-label="Primary">. The current one has aria-current="page" and a 2px gold inset underline. Hidden below 768px, where the tab bar takes over.
  4. Primary actionOne .btn--primary.btn--sm: List your business (signed in) or Join free (signed out).
  5. NotificationsGhost icon button with .topbar__dot (8px gold, --indicator-size). The count is in the button's aria-label, the dot is aria-hidden.
  6. Account.avatar--sm.avatar--brand initials linking to the account menu, labelled "Account menu for Joanna Adeyemi".

Variants

Pick the variant by who is looking, not by page: the ink bar is the same on browse, business and messages pages; only its links and trailing controls change. The admin application has its own bar, .admin-top, documented with its shell on Admin shell.

Sizes

The top bar has one height, --layout-topbar-height (64px); density does not change it. Its buttons use the small size from Button.

States

The bar itself has no states; its links and buttons do. Pointer and focus states are forced with data-state. Navigation links are never disabled: a destination the member cannot use is hidden, or opens a page that explains why (the forbidden mocks).

Both themes

jubilee
jubilee

Shown in the phone composition so both themes fit side by side.

  • Unread: the gold dot on the bell appears when there is at least one unread notification; it never shows a number. Counts on links use a .badge--count ("Messages 2").
  • Loading pages keep the full top bar; only the content area shows skeletons, so the member can still navigate away.
  • Offline keeps the bar; search submits are blocked by the offline banner, not by disabling the field.

Responsive behaviour

  • Below 768px (--layout-breakpoint-md) .topbar__nav, List your business and the avatar hide; the phone Tab bar carries Browse, List, Messages and You.
  • Below 1024px (--layout-breakpoint-lg) the search field hides and an icon-only ghost search button (.only-narrow) links to the search page.
  • At 360px the bar holds only the wordmark, search icon and bell: nothing wraps or truncates. Never add a fourth trailing control.
  • The bar is position: sticky at --z-sticky; the examples on this page set position: static so they stay in the flow.

Theming

The ink bar uses the brand-band tokens, which stay ink in both themes: the brand band is a fixed identity colour, not a surface that inverts. In dark the page around it darkens, so the bar reads as part of the page chrome rather than a band.

.topbar--ink { background: var(--color-bg-brand); color: var(--color-fg-on-brand); }
.topbar--ink :focus-visible { outline-color: var(--color-focus-ring-on-brand); }
.topbar--ink .btn--ghost { --btn-fg: var(--color-fg-on-brand); --btn-bg-hover: var(--color-bg-on-brand-subtle); }

The plain bar reads surface tokens and flips with the theme like any card.

Accessibility

Role and pattern

<header> at page level (banner landmark) containing a <nav aria-label="Primary"> and a role="search" form. Links are plain links marked with aria-current="page"; this is the APG landmark regions guidance, not a menubar. The account avatar should become a menu button in the product.

Keyboard

KeyAction
TabSkip link, wordmark, search, each nav link, primary action, search icon (narrow), notifications, account. DOM order equals visual order.
EnterFollows a link, submits search.
Enter / Space / ↓ on accountOpens the account menu (in product); Esc closes it and returns focus to the avatar.

Focus

The shared 2px ring, switched to --color-focus-ring-on-brand (gold) on the ink bar so it stays above 3:1 on ink. The sticky bar must not cover focused content: pages set scroll-padding-top to the bar height.

Labelling

Two nav landmarks exist on phones (top and tab bar) so each is labelled: "Primary" and "Primary, phone". The search input has a visually hidden label ("Search businesses and products"). Counts are spoken in full: "Messages, 2 unread", "Notifications, 3 unread".

Motion

Link colour and background transition over --duration-fast; reduced motion zeroes it through the token. The bar does not hide on scroll.

Touch

Nav links are --layout-topbar-height (64px) tall on the ink bar and at least --target-comfortable (44px) on the plain bar. Small buttons and the 32px avatar are spaced by --space-4, keeping the 24px target-spacing rule.

Content

  • Link labels are one noun: Browse, Messages. No more than three links.
  • The wordmark is lowercase "jubilee"; never replace it with the page title.
  • The single action is a verb phrase: List your business, Join free.
  • Search placeholder gives examples, not instructions: "Plumber, lawyer, Bibles…". The label carries the instruction.

Drift fixed during extraction: all 230 bars were identical and token-clean, so the structure is extracted as is. Two accessibility gaps remain in the mocks and are corrected here: unread counts used aria-label on a plain <span> (not announced reliably), now visually hidden text; and the account avatar is a link to a dialog page, which the product should build as a menu button. The plain .topbar is never used; it is kept as the base the ink variant extends. .btn--icon only gets position: relative inside .topbar--ink, so a dot on a plain bar mispositions; the plain example omits the dot.
