Empty state

An empty state fills the space where content would be: no saved businesses yet, no messages matching "roofing", requests that failed to load. It explains the gap in one sentence and offers the one thing that fills it.

WCAG 2.2 AAStatus: stable68 empty, no-results and error mocks

Overview

Use an empty state in place of a list, grid or panel that has nothing to show. For a whole page that cannot be shown (404, offline), use the Error page. While loading, use a Skeleton.

  • First use: nothing here yet. Explain the value and give the action that creates the first item ("Add product", "Browse businesses").
  • No results (often .empty--compact): a search or filter matched nothing. Echo the query and offer to clear it.
  • Error (.empty--error, role="alert"): the content failed to load. Say nothing is lost, offer Try again and a reference code.
  • Prompt: an idle pane that waits for a choice ("Pick a conversation"), with no action.

Anatomy

  1. Icon disc.empty__icon: 64px disc in --color-accent-subtle with a --icon-size-lg icon in --color-fg-accent; danger tints in the error variant. Decorative.
  2. Title.empty__title, --text-h3, an <h2> (or <h1> on an error page).
  3. Text.empty__text, muted, at most 36ch wide.
  4. Actions.empty__actions: one primary, optionally one secondary.

Disabled actions do not appear: if the person cannot act, the text says why and there is no button.

Responsive behaviour

  • Centred column at every width; text wraps at 36ch, so at 360px it is the width of the screen minus margins.
  • Two actions sit side by side and wrap to two centred rows when they do not fit.

Theming

The icon disc uses --color-accent-subtle and --color-fg-accent (warm gold tint in light, deep gold in dark). .empty--error swaps them for --color-danger-bg and --color-danger-icon.

Accessibility

Role and pattern

A heading plus text; no special role for first use and no results. Load errors use role="alert" so the failure is announced when it replaces a skeleton. A no-results state that appears after a search updates the results status region ("No messages match roofing"). See the APG alert pattern.

Keyboard

KeyAction
TabReaches the actions.
EnterActivates the focused action.

Focus

Focus is not moved to an empty state. After Clear search, focus returns to the search field.

Labelling

The heading is the message; the icon is aria-hidden. Use the right heading level for where it sits: <h2> under the page title.

Motion

None. The swap from skeleton to empty state is instant.

Touch

Actions are medium buttons (44px), --space-3 apart.

Content

  • First use: title says what will be here, text says how to fill it: "Save businesses to find them again. Tap the heart on any listing."
  • No results: echo the query in curly quotes, then the fix: "No messages match “roofing”. Check the spelling, or search by business name."
  • Error: "We couldn’t load your requests. Nothing is lost." plus a reference code like JB-REQ-503.
  • Never blame the person; never "No data".
