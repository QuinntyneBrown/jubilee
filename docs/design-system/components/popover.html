Popover

A popover is a raised panel that opens next to the button that triggered it and closes when you move on. It ships in the kit, but no mock uses it; the nearest thing is the user menu, which is a menu on desktop and a sheet on phones.

WCAG 2.2 AAStatus: kit, unusedKit only · 0 uses in the mocksNon-modal

Overview

Use a popover for a short explanation or one quick action that relates to a specific control, such as what Jubilee’s statement of faith asks of an owner, where it would be noise to show the text inline. Use a Tooltip for a one-line hint on hover or focus, a Menu for a list of actions, and a Dialog when the person must answer. Never put a form longer than one field in a popover.

  • Informational: a title and two sentences.
  • With actions: adds small buttons, at most two.

Anatomy

  1. TitleA short label in --text-label; it names the popover via aria-labelledby.
  2. TextTwo sentences at most, --text-body-sm, muted.
  3. Actions (optional)Up to two small buttons. The surface is --color-bg-surface-raised, hairline edge, --radius-md, --shadow-3, padding --space-4, max width 20rem.

Sizes

One size: width fits the content up to min(20rem, 90vw), padding --space-4.

States

A popover is closed or open; its trigger carries the state in aria-expanded. Pointer and focus states belong to the trigger and the actions inside; they are shown here with data-state.

Responsive behaviour

  • Max width min(20rem, 90vw), so it never runs off a 360px screen; flip it to open upwards or to the left when there is no room below or to the right.
  • On phones, prefer showing the text inline or in a bottom-sheet Dialog; a popover under a thumb is easy to lose.

Theming

Same surface as a menu: --color-bg-surface-raised, --color-border-default, --shadow-3. In dark mode the hairline edge carries the separation from the page.

Accessibility

Role and pattern

The trigger is a button with aria-expanded and aria-controls, as in the APG disclosure pattern. The panel is a non-modal role="dialog" with aria-labelledby. The native popover attribute with popovertarget gives light dismiss, Escape and top-layer placement without script and is the preferred build.

Keyboard

KeyAction
Enter, Space on the triggerOpens or closes.
TabMoves from the trigger into the popover's actions, then on; leaving closes it.
EscCloses and returns focus to the trigger.

Focus

Focus stays on the trigger when an informational popover opens; it moves to the first action when there is one. The shared ring is used.

Labelling

The popover is named by its title. The trigger's own name does not change when it opens; aria-expanded carries the state.

Motion

Appears without movement; if a fade is added it uses --duration-fast and is zeroed by reduced motion.

Touch

The trigger is a button of at least 32px with 8px around it, or 44px on phones; small buttons inside keep --space-2 apart.

Content

  • Title with the question it answers: "How listings stay honest".
  • Two sentences at most; link to Help for the rest.
  • Do not repeat the trigger label as the title.
