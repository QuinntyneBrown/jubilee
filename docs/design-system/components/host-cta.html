Running something?

The invitation to host, under “You’re going”: “Running something?”, one line, and “Host an event”, an ink button that opens the host form.

Overview

  • Shown to everyone. For a visitor, “Host an event” opens the sign-in prompt “Join to host an event” and returns to /events/new (L2-300 AC5).
  • One per screen, in the side column.

Anatomy

  1. Title.host-cta__title, semibold.
  2. Text.host-cta__text, muted.
  3. Action.btn.btn--ink.host-cta__action.

Responsive behaviour

In the side column from 1024 px; under it, after “You’re going” at the end of the page.

Theming

The rule above is --color-border-strong. The ink button is --color-bg-inverse, cream in dark.

Content

  • “Running something?”, “List a gathering, meetup or workshop for the community. Free for churches and members.” and “Host an event”, exactly.
  • Never promise a reach or a return for hosting (L2-312 AC6).
