Skip link

The skip link is the first thing a keyboard user reaches on every page. It stays out of sight until focused, then slides in and jumps past the top bar to the content.

Overview

Every page has exactly one skip link, as the first element in <body>, pointing at <main id="main">. This page has one too: press Tab once after loading it.

It exists because the Top bar puts up to eight stops (wordmark, search, links, buttons, avatar) before the content on every page (WCAG 2.4.1).

Anatomy

  1. Label"Skip to content", --color-fg-default.
  2. Container--color-bg-surface-raised, --radius-md, --shadow-3, --space-2 / --space-4 padding; positioned at --space-4 from the top-left at --z-tooltip when focused.

Responsive behaviour

  • Same on every width; it sits --space-4 from the top-left corner, over the top bar.
  • On touch devices without a keyboard it never appears.

Theming

Raised surface and default text, so it flips with the theme. It sits over the ink top bar, so it uses the raised surface rather than the brand band and its shadow separates it from the ink.

Accessibility

Role and pattern

A same-page link (<a href="#main">), the first focusable element. The target <main id="main"> receives focus. Satisfies WCAG 2.4.1 Bypass Blocks; see APG landmark regions.

Keyboard

KeyAction
Tab (first)Shows and focuses the skip link.
EnterMoves focus to main content; the next Tab continues inside it.
Tab (again)Hides it and moves to the wordmark.

Focus

Visible only on :focus-visible, with the shared ring on top of the raised surface. It must never be hidden with display: none or visibility: hidden, which would remove it from the tab order.

Labelling

"Skip to content" names where it goes.

Content

  • Always "Skip to content". Not "Skip navigation" or "Jump to main".
