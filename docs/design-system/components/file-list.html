File list

A file list lets a member add a few files to a form and see what they added: a dashed button that opens the file picker, each chosen file by name with “Remove”, and a line for a file that was refused.

WCAG 2.2 AAStatus: stableIn a fieldset fieldL2-212

Overview

Use it for the screenshots of a bug report: up to three JPEG or PNG pictures of 5 MB or less each. The files are sent with the form, not when they are chosen. For one photo sent in a conversation, the composer’s attach button is the pattern (Message thread).

Anatomy

  1. Legend and helpThe Form field’s legend and help, on a <fieldset>; they name and describe the group.
  2. Add button.file-list__add: a full-width button with a 2px dashed --color-border-strong edge, the image icon and its label.
  3. File iconDecorative, muted.
  4. Name.file-list__name, --text-label; one line, cut with an ellipsis.
  5. Remove.file-list__remove: a 44px text button named “Remove {file name}”.

Sizes

One size. The add button and the list fill the field’s width.

States

Forced with data-state.

Responsive behaviour

  • The add button and the rows fill the width at every size; a long file name is cut with an ellipsis so “Remove” stays on the row.
  • Rows are at least 44px tall through the “Remove” button.

Theming

The add button is a --color-bg-surface area with a dashed --color-border-strong edge (3:1 as a control edge); hover fills it with --color-bg-subtle. The list is a surface with hairline dividers. “Remove” is link-coloured and underlined.

Accessibility

Role and pattern

A plain container inside a <fieldset class="field">, whose legend names the group and whose help describes it. The add button is a native <button> that opens the browser’s file picker; the files are a <ul>.

Keyboard

KeyAction
TabThe add button, then each “Remove”.
Enter / Space on the add buttonOpens the file picker.
Enter / Space on “Remove”Removes that file; focus moves to the next “Remove”, or to the add button when none is left.

Focus

The shared ring: around the dashed area, and around each “Remove” as a pill.

Labelling

Each “Remove” names its file (aria-label="Remove request-still-sending.png"). The list is named “Screenshots added”. The error line is role="alert", so a refusal is announced.

Touch

Content

  • The button says what is added: “Add screenshots”.
  • The help says it is optional and why it helps: “Optional, but they help us fix it faster.”
  • Refusals say what to do: “Use a JPEG or PNG of 5 MB or less.” and “You can add up to three screenshots.”
  • A file is listed by the name it has on the member’s device.
