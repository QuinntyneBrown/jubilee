Component · Inputs

Text field

A text field takes one line of typed input: a name, an e-mail, a price, a day. It is always inside a form field with a visible label, except the search box, whose label is hidden but present.

Overview

Use a text field for short, free-form values. Use a Textarea for more than a sentence, a Select for a fixed list, and radios for two to five visible options. The label, help, error and counter belong to the Form field around it.

  • Text, e-mail, URL, number: one .input with the right type, autocomplete and inputmode.
  • Password: an .input-group with a Show toggle so members can check what they typed.
  • Search: .search wraps the input with a leading icon inside a role="search" form.
  • Date: the native date picker (book a meeting, request a quote); Jubilee does not ship a custom calendar.
  • Prefix add-on: .input-group .addon for a fixed unit such as $ on prices.
  • Read-only with action: the share dialog's link field with a Copy button.

Anatomy

  1. Label.field__label with a required/optional marker; see Form field.
  2. Help.field__help before the input, linked by aria-describedby.
  3. Input.input: 48px tall, 16px side padding, 12px --radius-md, hairline --color-border-strong edge (ink 15%), surface fill, 15px text.
  4. Counter.field__counter, right-aligned caption, also in aria-describedby.

Sizes

The default is 48px tall with 15px text and is used in every form. Small (40px, 14px text) is for inline toolbars such as Sort. .input--lg keeps the 48px height and sets 16px text.

.input--sm / default / .input--lg; heights from --control-height-md (small) and --control-height-lg.

Both themes

Use at least 10 characters. This one has 5.
Use at least 10 characters. This one has 5.
  • Hover darkens the edge to --color-fg-subtle.
  • Focus draws a 2px --color-focus-ring ring (ink in light) over the edge and hides the edge itself.
  • Invalid thickens the border to 2px in --color-danger-solid (border plus inset shadow), so the change is not colour alone, and the field shows its error text.
  • Read-only is used while a form submits (edit-listing submitting): values stay readable and selectable but cannot change.
  • Disabled is rare: a field that does not apply is hidden or explained, not greyed out.

Responsive behaviour

  • Inputs are fluid (width: 100%) and take their width from the form grid; two-column rows collapse to one under 640px.
  • Text is 15px (--text-body-md) at every width; the small size is 14px.
  • The top-bar search shows from 768px as a 40px pill; below that the search icon links to the search page, and the phone hero shows a 48px cream pill instead.
  • Add-ons keep their width; the input shrinks. Long read-only values scroll inside the input, never overflow.

Theming

Each field reads four component tokens set from semantic ones: --field-bg, --field-fg, --field-border, --field-border-hover. On the brand band the top-bar search is a 40px pill filled cream 10% (--color-bg-on-brand-subtle) with on-brand text and edge tokens.

.topbar--ink .search .input { background: var(--color-bg-on-brand-subtle); border-color: var(--color-border-on-brand); color: var(--color-fg-on-brand); }

In light the edge is ink 15%. In dark, inputs sit on the dark surface with a lighter strong border; placeholder text uses --color-fg-subtle, which holds 4.5:1 in both themes.

Accessibility

Role and pattern

Native <input> with the correct type. Search sits in a <form role="search">. The password toggle is a toggle button (APG button pattern) with aria-pressed and aria-controls. Native date inputs keep the browser's accessible picker.

Focus

A 2px --color-focus-ring outline (ink in light, gold in dark) drawn over the edge, which turns transparent, so one ring follows the field's 12px --radius-md corners. The top-bar search uses --color-focus-ring-on-brand.

Labelling

Every field has a visible <label for>; the search label is visually hidden. Help, error and counter ids go in aria-describedby. Placeholders are examples, never labels. Use autocomplete tokens (email, current-password, new-password, given-name, street-address) for 1.3.5.

Contrast

The light-theme edge follows the design reference: ink 15%, about 1.4:1 against the surface, below the 3:1 that 1.4.11 asks for. It is a recorded exception in tokens/contrast-pairs.json. The label above the field, the white fill on the cream page and the 2px focus ring identify the field; prefers-contrast: more restores a 3:1 edge.

Motion

Border colour and shadow transition over --duration-fast (150ms); reduced motion zeroes it.

Touch

Default fields are 48px tall and full width; small fields are 40px. The Show toggle stretches to the field's height. All clear the 24px minimum target.

Content

  • Labels are short nouns in sentence case: “E-mail”, “Business name”, “Price”. No colon.
  • Mark required and optional fields in words: “(required)”, “(optional)”.
  • Help text says what makes a good answer or a limit: “At least 10 characters.”
  • Placeholders, where used, are examples (“Plumber, lawyer, Bibles…”), never instructions.
  • Use Canadian formats: “$34.00”, dates as “Thu 12 Nov 2026” in text.
