Booking card

The booking card sits beside a space's title: the rent, the minimum stay and the one thing to do, with "Message host" and save. The request itself (dates, the short-stay total, a note) opens in the Request a space dialog.

WCAG 2.2 AAStatus: newL2-206

Overview

Use it once, on the space page, in the detail head. The call to action follows the term: "Request to book" (Short stay), "Request a viewing" (Long term, Room) or "Meet the household" (Roommate). The card holds no form: per ADR 0042 the dates live in dialogs/request-space. Under 768px the call to action moves to the booking bar fixed above the tab bar.

Anatomy

  1. Rent.booking-card__price, Archivo bold at --font-size-3xl.
  2. Unit.booking-card__unit, "/ night" or "/ month".
  3. Minimum.booking-card__minimum: "{minimum stay} min.", pushed to the end of the line.
  4. Actions.booking-card__actions: the primary call to action (flexes), "Message host" and save as icon buttons.
  5. Note.booking-card__note: "You won’t pay anything until the host accepts."

Sizes

One size; the card takes the width of the detail head column.

States

The card has no state of its own beyond requested; its buttons keep the Button states, and save is a toggle with aria-pressed.

Responsive behaviour

  • From 768px the actions row shows the call to action, "Message host" and save.
  • Under 768px the call to action is hidden in the card and shown in the booking bar, so it stays in reach while the page scrolls; the bar is not shown once a request is open (L2-205 AC4). The body gains bottom padding so the bar never covers the footer.
  • The price line wraps: the minimum moves under the rent on narrow columns.

Theming

--color-bg-surface with a hairline --color-border-default and --radius-xl. The sent box is --color-success-bg with --color-success-fg text and the heading in --color-fg-default.

Accessibility

Role and pattern

Plain structure with links and buttons. The call to action is a link that opens a dialog; save is a toggle button (aria-pressed); "Message host" and save are icon buttons named by aria-label. The sent box is role="status" so the confirmation is announced when it appears.

Shared ring on each control. After the dialog sends, focus returns to the card, which now holds the sent status.

The rent and minimum are text, never an image.

Content

  • Calls to action: "Request to book", "Request a viewing", "Meet the household", never "Book now" or "Rent".
  • "{minimum stay} min.": "2 nights min.", "12-month lease min.".
  • Sent: "Sent to {host first name}" and "You’ll hear back in Messages, usually within a day. The exact address is shared once they accept."
