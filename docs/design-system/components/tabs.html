Tabs

Tabs split one place into a few views. Jubilee uses them two ways: as a true tablist that filters a list in place (request type, result type, queue filter), and as page tabs that link between the sections of My business and Account.

Overview

Both forms look the same; their markup and keyboard model differ, so pick by what activating a tab does.

  • In-page tabs (div.tabs[role=tablist] of button.tab[role=tab]) switch a panel on the same page without a load: All · Bookings · Quotes · Orders · Declined on Your requests, Businesses · Services · Products on search results, the admin queue filter.
  • Page tabs (nav.tabs of a.tab) go to another page and mark the current one with aria-current="page": Overview · Listing · Products · Services · Requests in My business, Profile · Notification settings · Saved · Your requests in Account.
  • Use a Button group for a toggle between two or three views of the same data, and Chips for filters that combine.

Anatomy

  1. Selected tabSemibold, --color-fg-default, with a 2px gold indicator (::after, --radius-xs top corners).
  2. CountOptional .badge with the number of items in that view.
  3. Indicator--border-width-thick bar in --color-accent sitting over the list's hairline.
  4. Track.tabs: flex row, hairline bottom border, horizontal scroll with the scrollbar hidden.
  5. Panelrole="tabpanel", labelled by the selected tab, focusable when it has no focusable content.

Segmented

.tabs--segmented is a pill track whose selected tab is a raised pill; each tab holds an icon and its label. It leads the feedback panel and, with .tabs--lg, the feedback page. It is the same tab list: role="tablist", aria-selected, one tab in the tab order, arrow keys between them. The selected tab is told by its raised shape as well as its colour.

In the panel the track fills the width and the tabs share it.

Sizes

One size: tabs are --target-comfortable (44px) tall with --text-label. Dense contexts use a select instead.

States

Forced with data-state where no attribute exists; selection uses aria-selected and aria-current, disabled uses the native attribute.

Responsive behaviour

  • The track scrolls horizontally when tabs do not fit (overflow-x: auto, scrollbar hidden). At 360px the five My business tabs scroll; the current tab is scrolled into view on load.
  • Labels never wrap or truncate; shorten them instead ("Notification settings" is the longest allowed).
  • Beyond six tabs on a phone, switch to a Select labelled with the same name as the tablist.

Theming

Labels read --color-fg-muted and --color-fg-default and flip with the theme; the indicator stays gold. Counts use the neutral .badge; the open-requests count on page tabs uses the gold .badge--count.

Accessibility

Role and pattern

In-page: APG tabs pattern with automatic activation: role="tablist" with aria-label, role="tab" with aria-selected and aria-controls, role="tabpanel" with aria-labelledby. Page tabs: a labelled <nav> of links with aria-current="page", no tab roles.

Keyboard

KeyAction
TabIn-page: enters the tablist on the selected tab, next Tab goes to the panel. Page tabs: each link is a Tab stop.
← / →In-page: moves to and selects the previous / next tab, wrapping.
Home / EndIn-page: first / last tab.
EnterPage tabs: follows the link.

Focus

The shared 2px ring on the tab (:focus-visible). The panel is focusable (tabindex="0") only when it holds no focusable element.

Labelling

The tablist or nav is labelled by what it divides ("Request type", "My business sections"). The tab's name includes its count ("Bookings 1"); spell out the noun in visually hidden text when the number alone is unclear ("Requests, 3 open").

Motion

The indicator colour transitions over --duration-fast; it does not slide between tabs. Reduced motion zeroes it.

Touch

Each tab is 44px tall (--target-comfortable) with --space-3 padding and --space-1 between tabs.

Content

  • Tab labels are short nouns in sentence case: All, Bookings, Quotes, Orders, Declined.
  • The first in-page tab is the unfiltered view ("All").
  • Counts show what is in the view now, including zero.
  • Page tab labels match the page title they lead to.
