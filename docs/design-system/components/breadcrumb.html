Breadcrumb

A breadcrumb tells a member where a detail page sits and gives them one tap back to each level above it: the category, the shop, the request list.

WCAG 2.2 AAStatus: stable<nav> + <ol>46 uses in 42 mocks

Overview

Use a breadcrumb on pages two or more levels deep: category, product, request detail, help and legal pages, the admin verification detail. Do not use one on top-level pages reached from the top bar (Browse, Messages, Account) or as a replacement for the back link on phone-first flows.

  • Ancestors are links in --color-fg-muted; the current page is plain text in --color-fg-default, medium weight, with aria-current="page".
  • Separators are a slash drawn by CSS (li + li::before), so they are not read aloud.

Anatomy

  1. Ancestor link.breadcrumb a: --text-body-sm, muted, underlined on hover.
  2. Separator"/" from ::before in --color-fg-subtle, --space-2 each side; decorative.
  3. Current pageli[aria-current="page"]: not a link, --color-fg-default, --font-weight-medium.

Sizes

One size, --text-body-sm. It never grows on hero or detail headers.

States

Ancestor links have hover and focus; the current page has none. Forced with data-state.

Responsive behaviour

  • The list wraps (flex-wrap) rather than truncating; at 360px a long product name drops to a second line.
  • Never hide ancestors behind an ellipsis: Jubilee trails are at most three levels.
  • On phones the breadcrumb stays; it is the only way up from a product to its shop without the browser's back button.

Theming

Text tokens only; flips with the theme. No brand-band form: detail-page headers are on the canvas, never on ink.

Accessibility

Role and pattern

<nav aria-label="Breadcrumb"> around an <ol>; the last item has aria-current="page". See the APG breadcrumb pattern.

Keyboard

KeyAction
TabMoves through the ancestor links; the current page is not a stop.
EnterFollows the link.

Focus

The shared 2px ring around the link text.

Labelling

The landmark is labelled "Breadcrumb". Separators come from CSS and are not announced; the list semantics give "list, 3 items".

Motion

None.

Touch

Crumbs are inline text at --text-body-sm, so below 24px tall; the --space-2 separators on each side keep the 24px spacing exception (2.5.8). Detail pages also offer a back link of 44px for touch.

Content

  • Each crumb is the destination's page title, unshortened: "Home & property", "Luzandre.com".
  • The current page is the page's h1, verbatim.
  • Never start with "Home": Jubilee's root is Browse.
