Directory row

Directory rows are the A–Z of Jubilee: every verified business in a category, one row each, with its name, its pitch and a chevron. Groups of rows sit under a category heading with a count and a "See all" link.

Overview

Use directory rows when the person is scanning many businesses by name: All 47 businesses on browse, a category's full list, search results by business. When pictures help people choose (shops, featured), use a Business card grid instead. For rows that carry actions (Book, Edit) use the List or Table.

  • Row (.dir-row): name with the verified check, a one-line tagline and a trailing chevron. The whole row is one link.
  • Group (.dir-group): a section labelled by its h3 category heading, a count, the rows and an optional .dir-more "See all 6" link.
  • Groups (.dir-groups): one column on phones, two columns from 768px, three from 1024px.

Anatomy

  1. Group heading.dir-group__head h3, --text-subhead (14px semibold), hairline rule below.
  2. Count.dir-group__count, --text-meta (13px), tabular, muted. Visible number plus a hidden "6 businesses".
  3. Name.dir-row__name: --text-body-md at medium weight (15px); truncates with an ellipsis.
  4. Verified check--icon-size-xs (14px), --color-success-icon, followed by a visually hidden "Verified".
  5. Tagline.dir-row__tagline: --text-meta (13px) muted, one line, truncated.
  6. ChevronTrailing 16px chevron-right in --color-fg-muted, aria-hidden. It moves 2px right on hover.
  7. See all.dir-more: a 13px semibold green link to the full category, at least 24px tall.

Variants

There is one row. Groups vary by whether the list is complete (no See all) or a preview (See all N).

Sizes

One size. The row is at least 44px (--target-comfortable) and grows with its two lines; density never changes.

States

The row has no hover fill. On hover the chevron moves 2px to the right (--space-0-5) over --duration-fast; press has no look of its own, so the Active cell matches Default. Focus draws the shared ring around the row. Hover and focus have real data-state hooks.

  • Last row: the last row in a list has no divider.
  • Loading: skeleton rows of the same height (two text bars), list aria-hidden, one role="status" line.
  • No results in a category or search is an Empty state with a way out ("Clear filters", "Browse all"), never an empty group heading.
  • Unread / new markers are not part of the directory; a new business shows up in notifications.

Responsive behaviour

  • Below 768px groups stack in one column; from 768px .dir-groups becomes two equal columns and from 1024px three, with a --space-10 (40px) gap.
  • Rows are full width; name and tagline truncate at any width so every row stays two lines. At 360px about 30 characters of tagline remain.
  • The chevron and the row height never change. Nothing hides at small sizes.

Theming

Rows are always transparent, so they work on the canvas and on a surface. There is no hover or active fill; dividers use --color-border-default, and the verified check uses --color-success-icon, which holds 3:1 on the canvas in both themes.

Accessibility

Role and pattern

Each group is a <section aria-labelledby> named by its h3, holding a <ul> of rows; each row is one native link. See the APG link pattern.

Keyboard

KeyAction
Tab / Shift+TabMoves row to row, then to See all, then into the next group.
EnterOpens the business.
Screen-reader heading and list keysJump between category headings (H) and lists (L); the count is read after the heading.

Focus

The shared ring (2px --color-focus-ring, 2px offset) surrounds the row; the chevron does not move on focus alone, so the ring is the only cue.

Labelling

The row's name is "Legacy Financial Verified Build a Legacy…": the visible name, the hidden "Verified", then the tagline. The count shows the number and a visually hidden "6 businesses"; it does not rely on aria-label on a plain span, which screen readers ignore. See all names the count ("See all 6") and sits under its heading, so its context is clear.

Motion

The chevron shifts 2px over --duration-fast (150ms) with --ease-standard; reduced motion zeroes the duration. Nothing else moves.

Touch

Each row is at least 44px tall (--target-comfortable) and full width. See all is at least 24px tall (--target-min) and gets a 44px touch hit area on coarse pointers. Rows touch, but each is a single target with no inner controls.

Content

  • Group headings are the category names from the taxonomy, with an ampersand: "Financial & insurance", "Legal & immigration".
  • The count is the total in the category, not the rows shown. See all repeats it: "See all 6".
  • The tagline is the business's own pitch, the same one as on its card. Put the useful words first; it truncates.
  • Do not add prices, ratings or distance to rows. If a fact decides the tap, it belongs on a business card.
