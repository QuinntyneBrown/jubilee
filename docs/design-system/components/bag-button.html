Bag button

The bag, with the number of shirts in it. It opens the bag.

WCAG 2.2 AAStatus: newbag-buttonL2-266
  • Overview

Overview

  • In the Purpose Tee page’s own header row, right of the back link. The app’s top bar has no bag: it is the same on every screen.

Anatomy

  1. ButtonA pill with a hairline edge, the bag icon and “Bag”.
  2. CountThe number of shirts; filled ink when the bag holds any. Hidden from assistive technology: the button’s name says it.

Sizes

One size, 44 px tall.

States

Default, hover, focus. It is never disabled: an empty bag opens and says so.

Responsive behaviour

The same at every width.

Theming

The filled count is the inverse pair in both themes.

Accessibility

Named “Bag, {n} items” (“1 item”), with aria-haspopup="dialog". The number is said in the name, so the filled count is not the only sign.
