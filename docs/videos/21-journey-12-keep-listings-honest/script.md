# 21 · Journey 12: Keep listings honest

The transcript, written from `narration.json` by `tools/video-demo/build.mjs`.

Journey twelve: keep listings honest. Owners publish and are live straight away. The Jubilee team looks through what was published, and takes down a listing that misrepresents a business.

Listings shows every published listing, newest first, with its status. A name or tagline with a web address or a discount code is tagged Flagged.

A search by name keeps the listings that match.

One listing shows where it stands, its owner and their other listings, the flag, and how members see it. Opening it is now written to the audit log, with the listing as the reason.

Take down listing asks for a reason for the owner. Without one, nothing is sent.

With a reason, the listing leaves Jubilee at once, the owner is e-mailed why, and the page says so. The owner may list again.

Behind the screen, each role change made with the jubilee staff command is now audited, with its operator and the roles before and after. The tests prove it.

Journey twelve is complete. Nothing in the admin application approves, declines or verifies a listing.
